## ❌ Critical Bug: Assembler Immediate Value Encoding

### Problem
The assembler (`rawrxd_native_assembler.exe`) has a bug where it encodes `mov eax, 42` as `mov eax, eax` (8B C0 instead of B8 2A 00 00 00).

### Evidence
```
Object file dump at code section:
  8B C0 C3  =  mov eax, eax; ret
  
Expected:
  B8 2A 00 00 00 C3  =  mov eax, 42; ret
```

### Root Cause
The assembler's instruction selection logic is matching the wrong encoding from the instruction table. When it sees `mov eax, 42`, it's selecting the register-to-register encoding instead of the immediate encoding.

### Impact
- Simple programs without immediate values work fine
- Any program that needs to load constants into registers fails
- This blocks the Sovereign Engine build (which uses many immediate values)
