## 🚀 Quick Start

### RawrXD-Win32IDE.exe
```cmd
RawrXD-Win32IDE.exe
```
Launches the full IDE with Win32 GUI, WebView2, and all features.

### RawrEngine.exe
```cmd
RawrEngine.exe --version
RawrEngine.exe --help
```
Headless inference engine for command-line usage.

### RawrXD_Gold.exe
```cmd
RawrXD_Gold.exe
```
Standalone deployment build with all MASM kernels linked.
