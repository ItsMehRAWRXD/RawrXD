## 1. Curriculum Overview

The Sovereign IDE Training Curriculum provides a structured learning path for developers at all levels, from beginners to advanced users working with agentic systems, MoE architectures, and frontier-scale models.

### 1.1 Learning Paths

| Path | Target Audience | Duration | Prerequisites |
|------|----------------|----------|---------------|
| **Foundation** | New users | 2 weeks | None |
| **Developer** | Software developers | 4 weeks | Programming experience |
| **Advanced** | Senior developers | 6 weeks | C/C++, MASM knowledge |
| **Expert** | System architects | 8 weeks | All previous paths |
| **Agentic** | AI developers | 6 weeks | Python, ML basics |
| **MoE Specialist** | Model engineers | 8 weeks | Deep learning, CUDA |
