# RawrXD Mega Unified System v5.0
## Installation Guide

### System Requirements
- Windows 10/11
- 4GB RAM minimum
- 1GB disk space
- Visual C++ Redistributable

### Installation
1. Run `setup.exe`
2. Follow installation wizard
3. Launch from Start Menu or Desktop

### Quick Start
```cmd
RawrXD-Mega> stats
RawrXD-Mega> search <tool>
RawrXD-Mega> run <tool_id>
```
