CANONICAL EXECUTION WITNESS (v1.1 with configuration_hash)

struct ExecutionWitness {
    // Identity
    UUID execution_id;              // v4 UUID — correlation anchor
    
    // Input Identity (decomposed)
    Hash256 prompt_hash;            // SHA256(prompt text)
    Hash256 configuration_hash;     // SHA256(seed, temp, top_k, etc.)
    Hash256 input_hash;             // SHA256(prompt + config)
    
    // Runtime Identity
    Hash256 model_hash;             // SHA256(GGUF file)
    Hash256 runtime_hash;           // SHA256(rawrxd.exe)
    
    // Timing
    uint64_t start_timestamp;       // Unix nanoseconds
    uint64_t end_timestamp;
    
    // Stage Witnesses
    std::vector<StageWitness> stages;
    
    // Output Identity
    Hash256 final_output_hash;      // SHA256(generated text)
    
    // Validation
    bool deterministic;             // Replay match
    bool correlated;                // All stages linked
};

Identity Chain:
  prompt_hash + configuration_hash + model_hash + runtime_hash = execution identity

This distinguishes:
  • Same prompt, different sampler → different execution
  • Same model, different context → different execution
  • Same runtime, different quant → different execution

BACKPRESSURE SAFETY (VAL-063.12A)

Producer (Inference Thread)
       │
       ▼ push(event)
       │
       ├── buffer.size() < high_watermark?
       │       │
       │       YES → accept, notify consumer
       │       │
       │       NO → block on producer_cv_
       │              (yield producer thread)
       │
Consumer (Client)
       │
       ▼ pop()
       │
       ├── buffer not empty?
       │       │
       │       YES → return event
       │       │
       │       NO → wait on consumer_cv_
       │
       └── buffer.size() <= low_watermark?
               │
               YES → notify producer (resume)

Guarantees:
  • bounded memory growth
  • ordered delivery
  • zero token loss
  • deterministic blocking/yield
  • measurable overload behavior

Enables: Ghost text, Monaco streaming, Agent loops, Tool invocation

REPLAY VERIFICATION (VAL-063.9)

Original Execution:
  prompt_hash: sha256("The quick brown fox")
  configuration_hash: sha256({seed:42, temp:0.0, top_k:1})
  model_hash: sha256(ministral3_q4_0.gguf)
  runtime_hash: sha256(rawrxd.exe)
  output_hash: sha256(" jumps over...")

Replay Execution:
  Same prompt_hash
  Same configuration_hash
  Same model_hash
  Same runtime_hash
  → output_hash should match

Result: deterministic = (original_output_hash == replay_output_hash)

This is one of the strongest certification artifacts.
