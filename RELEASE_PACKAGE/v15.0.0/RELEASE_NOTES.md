# RawrXD v15.0.0 Release Notes 
 
## Overview 
RawrXD v15.0.0 represents the first **Sovereign Release** - a self-driving 
development environment with native transpilation capabilities. 
 
## Components 
 
### Core Binaries (35 executables) 
- **RawrXD.exe** - Main IDE launcher 
- **RawrXD_IDE.exe** - Native Win32 IDE 
- **RawrXD-Win32IDE.exe** - Alternative IDE 
- **RawrEngine.exe** - Core inference engine (4.1MB) 
- **SovereignTranspiler.exe** - Universal transpiler (PHP/C/Python to native) 
- **BeaconDebugger.exe** - System debugger 
- Plus 29 additional tools and utilities 
 
### Runtime DLLs (9 components) 
- Core runtime, GPU kernels, QuickJS bridge, Security manager 
- Inference engine, Agent runtime, Checkpoint manager 
- WebSocket server, File watcher 
 
## Features 
- **Sovereign Universal Transpiler**: Compile PHP/C/Python to native x64 
- **AI-Powered Agent**: Self-driving code generation and modification 
- **Native Win32 IDE**: Zero-dependency Windows interface 
- **SME2 Acceleration**: ARM64 SME2 support (simulated on x86_64) 
- **Checkpoint/Rollback**: Full state management 
 
## Installation 
1. Extract RawrXD-v15.0.0.zip to desired location 
2. Run `bin\RawrXD.exe` to launch IDE 
3. Run `verify_release.bat` to verify integrity
