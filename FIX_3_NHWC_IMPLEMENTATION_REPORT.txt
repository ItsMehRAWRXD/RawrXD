3. ARCHITECTURE
=============================================================================

Before (NCHW - Planar Layout):
------------------------------
Memory: [N][C][H][W]
Access: strided, cache-unfriendly
AVX-512: gather instructions needed (high latency)

  Example: Access all channels at spatial location (h, w)
  - Must gather from C different memory locations
  - Cache misses for each channel
  - ~20-30 cycles per gather

After (NHWC - Interleaved Layout):
----------------------------------
Memory: [N][H][W][C]
Access: contiguous, cache-friendly
AVX-512: contiguous loads (1 cycle)

  Example: Access all channels at spatial location (h, w)
  - Single contiguous 64-byte load (16 floats)
  - All channels in same cache line
  - ~3-4 cycles for 16 elements

Performance Gain: 5-8x faster channel access
