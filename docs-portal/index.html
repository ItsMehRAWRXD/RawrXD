Introduction

RawrXD is a sovereign AI runtime built for production inference at scale. It combines native x64 MASM performance with hotpatch-capable architecture, enabling zero-downtime updates and autonomous operation.

Quick Start

# Install via Chocolatey
choco install rawrxd

# Or download MSI installer
# https://github.com/itsmehrawrxd/rawrxd/releases/latest

# Verify installation
rawrxd --version

# Run quick benchmark
rawrxd benchmark --quick
# Install via Homebrew
brew install rawrxd

# Or download DMG
# https://github.com/itsmehrawrxd/rawrxd/releases/latest

# Verify installation
rawrxd --version

# Run quick benchmark
rawrxd benchmark --quick
# Download AppImage
wget https://github.com/itsmehrawrxd/rawrxd/releases/latest/download/RawrXD-x86_64.AppImage
chmod +x RawrXD-x86_64.AppImage

# Or install via package manager
sudo dpkg -i rawrxd_*.deb

# Verify installation
rawrxd --version

# Run quick benchmark
rawrxd benchmark --quick
# Pull the image
docker pull ghcr.io/itsmehrawrxd/sovereign-runtime:latest

# Run inference
docker run -p 8080:8080 \
  -v $(pwd)/models:/models \
  ghcr.io/itsmehrawrxd/sovereign-runtime:latest

# Or use docker-compose
docker-compose up -d

API Overview

RawrXD provides a RESTful API for inference, streaming, and management. All endpoints return JSON and support standard HTTP methods.

POST /v1/inference Generate completion
POST /v1/inference/stream Stream tokens
GET /v1/models List loaded models
POST /v1/models/load Load a model
GET /v1/metrics Get runtime metrics
POST /v1/hotpatch Apply hotpatch
