Turning a “plain” LLM into an agentic one is just engineering: you wrap the model in a loop that lets it
think
call tools
observe results
repeat until the job is done
Below is the minimal recipe you can copy-paste and extend.
(Everything is OSS, works on your laptop, no paid services.)

# tools.py
import json, subprocess, datetime, requests

def shell(cmd: str) -> str:
    """Run a shell command and return stdout+stderr."""
    try:
        out = subprocess.run(cmd, shell=True, capture_output=True, text=True, timeout=15)
        return out.stdout.strip() + out.stderr.strip()
    except Exception as e:
        return str(e)

def python(code: str) -> str:
    """Execute Python code and return str(repr(last expression))."""
    try:
        loc = {}
        exec(code, {"__builtins__": __builtins__}, loc)
        return str(loc.get("_", "ok"))
    except Exception as e:
        return str(e)

def web_search(query: str) -> str:
    """DuckDuckGo zero-click API: first 5 links/snippets."""
    r = requests.get("https://api.duckduckgo.com",
                     params={"q": query, "format": "json", "no_html": 1, "skip_disambig": 1}, timeout=10)
    return json.dumps(r.json().get("RelatedTopics", [])[:5], indent=2)

# expose them in a dict
TOOLS = {f.__name__: f for f in (shell, python, web_search)}
The agent loop (≈ 40 lines)

# agent.py
import ollama, json, traceback, tools

MODEL = "hf.co/bartowski/Llama-3.2-1B-Instruct-GGUF:Q4_K_M"

SYSTEM = """You are Agent-1B.
You may invoke these tools:
- shell(cmd)        run CLI commands
- python(code)      execute Python
- web_search(query) quick web lookup

Call a tool by replying EXACTLY:
TOOL:{name}:{arg_json}

When you have the final answer, reply:
ANSWER: <your answer>
"""

def invoke(tool_call: str):
    """Parse TOOL:name:json -> run -> return string."""
    _, name, arg_json = tool_call.split(":", 2)
    return str(tools.TOOLS[name](json.loads(arg_json)))

def agent(prompt: str):
    messages = [{"role": "system", "content": SYSTEM},
                {"role": "user", "content": prompt}]
    while True:
        reply = ollama.chat(model=MODEL, messages=messages)["message"]["content"]
        print("🤖", reply)
        if reply.startswith("ANSWER:"):
            return reply[7:].strip()
        if reply.startswith("TOOL:"):
            try:
                obs = invoke(reply)
                print("🔧", obs[:200] + ("…" if len(obs) > 200 else ""))
                messages.extend([{"role": "assistant", "content": reply},
                                 {"role": "user", "content": f"Observation: {obs}"}])
            except Exception as e:
                messages.append({"role": "user", "content": f"Tool error: {traceback.format_exc()}"})
        else:  # model forgot the format → remind
            messages.append({"role": "user", "content": "Use TOOL:... or ANSWER:..."})

if __name__ == "__main__":
    import sys
    result = agent(" ".join(sys.argv[1:]))
    print("\n✅ FINAL ANSWER:", result)

Make it stronger (iterate)
| Problem | Fix |
|---|---|
| Model forgets format | Increase size (3 B) or add “format checker” node |
| Too many round-trips | Let the model batch several TOOL calls in one reply |
| Long planning | Add an inner “scratchpad” role or use chain-of-thought |
| Persistent memory | Dump messages to disk / vector DB and reload next session |
| Structured output | Demand JSON after ANSWER: or use pydantic + guardrails |
Key idea you can reuse everywhere
“Agentic” = ReAct (Reason-Act-Observe) loop:
System prompt + tools + while-loop → any LLM becomes an agent.
Swap Ollama for OpenAI, Gemini, Claude, etc.—the scaffolding is identical.

Pure PowerShell Agentic Framework
<#
.SYNOPSIS
    Minimal Agentic Framework for Ollama - PowerShell version
.DESCRIPTION
    Turns any Ollama model into an agentic one using a ReAct loop:
    1. Think
    2. Call tools
    3. Observe results
    4. Repeat until done
#>

param(
    [Parameter(Mandatory=$true, Position=0)]
    [string]$Prompt,
    
    [Parameter(Mandatory=$false)]
    [string]$Model = "bigdaddyg-personalized-agentic:latest",
    
    [Parameter(Mandatory=$false)]
    [int]$MaxIterations = 10,
    
    [Parameter(Mandatory=$false)]
    [string]$OllamaServer = "http://localhost:11434"
)

$ErrorActionPreference = "Continue"

# ============================================
# TOOLS - Define what the agent can do
# ============================================

$script:TOOLS = @{}

# Shell command execution
function Invoke-ShellTool {
    param([string]$cmd)
    try {
        $output = & powershell -Command $cmd 2>&1 | Out-String
        return $output.Trim()
    }
    catch {
        return "Error: $_"
    }
}
$script:TOOLS["shell"] = ${function:Invoke-ShellTool}

# PowerShell code execution
function Invoke-PowerShellTool {
    param([string]$code)
    try {
        $result = Invoke-Expression $code
        if ($null -eq $result) { return "ok" }
        return ($result | Out-String).Trim()
    }
    catch {
        return "Error: $_"
    }
}
$script:TOOLS["powershell"] = ${function:Invoke-PowerShellTool}

# File operations
function Invoke-ReadFileTool {
    param([string]$path)
    try {
        if (Test-Path $path) {
            return Get-Content $path -Raw
        }
        return "Error: File not found: $path"
    }
    catch {
        return "Error: $_"
    }
}
$script:TOOLS["read_file"] = ${function:Invoke-ReadFileTool}

function Invoke-WriteFileTool {
    param([string]$path], [string]$content)
    try {
        $content | Set-Content -Path $path -Force
        return "File written successfully: $path"
    }
    catch {
        return "Error: $_"
    }
}
$script:TOOLS["write_file"] = ${function:Invoke-WriteFileTool}

# Web search (using DuckDuckGo)
function Invoke-WebSearchTool {
    param([string]$query)
    try {
        $url = "https://api.duckduckgo.com/?q= $([System.Web.HttpUtility]::UrlEncode($query))&format=json&no_html=1&skip_disambig=1"
        $response = Invoke-RestMethod -Uri $url -TimeoutSec 10
        $results = @()
        if ($response.RelatedTopics) {
            $results = $response.RelatedTopics | Select-Object -First 5 | ForEach-Object {
                @{
                    Text = $_.Text
                    FirstURL = $_.FirstURL
                }
            }
        }
        return ($results | ConvertTo-Json -Depth 3)
    }
    catch {
        return "Error: $_"
    }
}
$script:TOOLS["web_search"] = ${function:Invoke-WebSearchTool}

# List directory
function Invoke-ListDirTool {
    param([string]$path = ".")
    try {
        $items = Get-ChildItem -Path $path -ErrorAction SilentlyContinue | Select-Object Name, Length, LastWriteTime
        return ($items | ConvertTo-Json -Depth 2)
    }
    catch {
        return "Error: $_"
    }
}
$script:TOOLS["list_dir"] = ${function:Invoke-ListDirTool}

# ============================================
# AGENT LOOP
# ============================================

$SYSTEM_PROMPT = @"
You are Agent-1B, an agentic AI assistant powered by Ollama.

You may invoke these tools:
- shell(cmd)           Run PowerShell/CLI commands
- powershell(code)     Execute PowerShell code
- read_file(path)      Read a file's contents
- write_file(path, content)  Write content to a file
- web_search(query)    Search the web using DuckDuckGo
- list_dir(path)       List directory contents

Call a tool by replying EXACTLY in this format:
TOOL:{name}:{json_args}

Example:
TOOL:shell:{"cmd": "Get-ChildItem | Measure-Object | Select-Object -ExpandProperty Count"}

When you have the final answer, reply:
ANSWER: <your answer>

Think step by step. Use tools when needed. Always provide a final ANSWER.
"@

function Invoke-Tool {
    param([string]$toolCall)
    
    if (-not $toolCall -match "^TOOL:([^:]+):(.+)$") {
        return "Error: Invalid tool call format. Use TOOL:name:json_args"
    }
    
    $toolName = $matches[1]
    $argJson = $matches[2]
    
    if (-not $script:TOOLS.ContainsKey($toolName)) {
        return "Error: Unknown tool '$toolName'. Available: $($script:TOOLS.Keys -join ', ')"
    }
    
    try {
        $args = $argJson | ConvertFrom-Json
        $toolFunc = $script:TOOLS[$toolName]
        
        # Convert args object to hashtable for splatting
        $argHash = @{}
        $args.PSObject.Properties | ForEach-Object {
            $argHash[$_.Name] = $_.Value
        }
        
        $result = & $toolFunc @argHash
        return $result
    }
    catch {
        return "Error: $_"
    }
}

function Start-AgenticLoop {
    param([string]$UserPrompt)
    
    $messages = @(
        @{ role = "system"; content = $SYSTEM_PROMPT },
        @{ role = "user"; content = $UserPrompt }
    )
    
    $iteration = 0
    
    while ($iteration -lt $MaxIterations) {
        $iteration++
        Write-Host "`n[Iteration $iteration]" -ForegroundColor Cyan
        
        try {
            # Call Ollama
            $requestBody = @{
                model = $Model
                messages = $messages
                stream = $false
            } | ConvertTo-Json -Depth 10
            
            $response = Invoke-RestMethod -Uri "$OllamaServer/api/chat" -Method POST `
                -Body $requestBody -ContentType "application/json" -TimeoutSec 60
            
            $reply = $response.message.content
            Write-Host "🤖 Agent: $reply" -ForegroundColor Yellow
            
            # Check for final answer
            if ($reply -match "^ANSWER:\s*(.+)$") {
                $finalAnswer = $matches[1].Trim()
                Write-Host "`n✅ FINAL ANSWER: $finalAnswer" -ForegroundColor Green
                return $finalAnswer
            }
            
            # Check for tool call
            if ($reply -match "^TOOL:") {
                $observation = Invoke-Tool -toolCall $reply
                $obsPreview = if ($observation.Length -gt 200) { 
                    $observation.Substring(0, 200) + "…" 
                } else { 
                    $observation 
                }
                Write-Host "🔧 Tool Result: $obsPreview" -ForegroundColor Magenta
                
                # Add to conversation
                $messages += @{ role = "assistant"; content = $reply }
                $messages += @{ role = "user"; content = "Observation: $observation" }
            }
            else {
                # Model forgot format - remind it
                Write-Host "⚠️  Format reminder sent" -ForegroundColor Yellow
                $messages += @{ role = "assistant"; content = $reply }
                $messages += @{ role = "user"; content = "Use TOOL:name:json_args or ANSWER: your_response" }
            }
        }
        catch {
            Write-Host "❌ Error: $_" -ForegroundColor Red
            $messages += @{ role = "user"; content = "Error occurred: $_" }
        }
    }
    
    Write-Host "`n⚠️  Max iterations reached. Returning last response." -ForegroundColor Yellow
    return $reply
}

#Requires -Version 5.1
<#
.SYNOPSIS    Minimal yet elegant agentic loop for any Ollama model (PowerShell edition)
.DESCRIPTION ReAct loop: THINK → TOOL → OBSERVE → … → ANSWER.  Add tools by dropping a function in the plugin block.
#>
[CmdletBinding()]
param(
    [Parameter(Mandatory, Position = 0)][string]$Prompt,
    [string]$Model = 'bigdaddyg-personalized-agentic:latest',
    [int]$MaxIter  = 10,
    [Uri]$Ollama   = 'http://localhost:11434'
)

$ErrorActionPreference = 'Stop'
[Net.ServicePointManager]::SecurityProtocol = [Net.SecurityProtocolType]::Tls12

# -------------------------------------------------
# 1.  Micro plugin registry  ––  add your own here
# -------------------------------------------------
$PLUG = @{}

function Register-Tool {
    param($Name, $Func)
    $PLUG[$Name] = $Func
    $PLUG["${Name}_schema"] = (Get-Command $Func).Parameters.Keys.Where{ $_ -ne 'args' } -join ', '
}

# ---------- core tools ----------
function shell        ($cmd)          { pwsh -NoP -C $cmd 2>&1 | Out-String }
function powershell   ($code)         { Invoke-Expression $code | Out-String }
function read_file    ($path)         { Get-Content $path -Raw }
function write_file   ($path, $text) { $text | Set-Content $path -Force; "ok" }
function list_dir     ($path = '.')   { Get-ChildItem $path | Select Name, Length, LastWriteTime | ConvertTo-Json }
function web_search   ($query) {
    $uri = "https://api.duckduckgo.com/?q=$([uri]::EscapeDataString($query))&format=json&no_html=1&skip_disambig=1"
    $r = Invoke-RestMethod $uri -Timeout 10
    ($r.RelatedTopics + @{Text=$r.Abstract; FirstURL=$r.AbstractURL}) | Select -First 5 | ConvertTo-Json
}
# ---------- new tools ----------
function download_file($url, $out = (Split-Path -Leaf $url)) {
    Invoke-WebRequest $url -OutFile $out; "saved → $out"
}
function unzip        ($zip, $dest = '.') { Expand-Archive $zip $dest -Force; "ok" }
function hash_file    ($path, $algo = 'sha256') { (Get-FileHash $path -Algorithm $algo).Hash }
function reg_get      ($key, $value = '') { (Get-ItemProperty "Registry::$key" -Name $value -ErrorAction SilentlyContinue).$value }
function env_get      ($name) { [Environment]::GetEnvironmentVariable($name) }
function env_set      ($name, $val, $scope = 'Process') { [Environment]::SetEnvironmentVariable($name, $val, $scope); "ok" }
function clipboard    ($text = '') { if ($text) { Set-Clipboard $text; "ok" } else { Get-Clipboard } }
function speak        ($text) { Add-Type -AssemblyName System.Speech; (New-Object System.Speech.Synthesis.SpeechSynthesizer).Speak($text); "ok" }
function read_json    ($path) { Get-Content $path -Raw | ConvertFrom-Json | ConvertTo-Json -Depth 10 }
function read_yaml    ($path) { ConvertFrom-Yaml (Get-Content $path -Raw) | ConvertTo-Json -Depth 10 }
function csv_to_json  ($path) { Import-Csv $path | ConvertTo-Json }

# register everything
'shell', 'powershell', 'read_file', 'write_file', 'list_dir', 'web_search',
'download_file', 'unzip', 'hash_file', 'reg_get', 'env_get', 'env_set',
'clipboard', 'speak', 'read_json', 'read_yaml', 'csv_to_json' |
    ForEach-Object { Register-Tool $_ (Get-Command "function:$_") }

# -------------------------------------------------
# 2.  ReAct prompt – unchanged token count
# -------------------------------------------------
$SYS = @"
You are Agent-1B, an agentic assistant.
Tools: $($PLUG.Keys.Where{$_ -notmatch '_schema'} -join ', ')
Call: TOOL:name:{"arg":"value"}
Reply: ANSWER: <final answer>
"@

# -------------------------------------------------
# 3.  Tiny ReAct engine
# -------------------------------------------------
function Invoke-ToolCall {
    param($call)
    if ($call -match '^TOOL:([^:]+):(.+)$') {
        $name, $json = $Matches[1..2]
        if (!$PLUG.ContainsKey($name)) { return "Unknown tool" }
        try {
            $h = @{}
            ($json | ConvertFrom-Json).PSObject.Properties | ForEach-Object { $h[$_.Name] = $_.Value }
            & $PLUG[$name] @h | Out-String
        }
        catch { "Error: $_" }
    }
    else { "Bad format" }
}

function Start-AgenticLoop {
    param($UserPrompt)
    $msgs = @(
        @{ role = 'system'; content = $SYS },
        @{ role = 'user';   content = $UserPrompt }
    )
    1..$MaxIter | ForEach-Object {
        Write-Host "[Iter $_]" -Foreground Cyan
        $resp = Invoke-RestMethod "$Ollama/api/chat" -Method Post -ContentType app/json -Body (
            @{ model = $Model; messages = $msgs; stream = $false } | ConvertTo-Json -Depth 10
        )
        $txt = $resp.message.content
        Write-Host "Agent: $txt" -Foreground Yellow
        if ($txt -match '^ANSWER:\s*(.+)') { Write-Host "`n✅ $($Matches[1])" -Foreground Green; return $Matches[1] }
        if ($txt -match '^TOOL:') {
            $obs = Invoke-ToolCall $txt
            $obs = if ($obs.Length -gt 3000) { $obs.Substring(0, 3000) + '…' } else { $obs }
            Write-Host "Tool -> $obs" -Foreground Magenta
            $msgs += @{ role = 'assistant'; content = $txt }, @{ role = 'user'; content = "Observation: $obs" }
        }
        else { $msgs += @{ role = 'user'; content = 'Use TOOL:name:json or ANSWER: text' } }
    }
    "Max iterations reached"
}

# -------------------------------------------------
# 4.  Go
# -------------------------------------------------
Write-Host "Agentic loop – model $Model" -Foreground Cyan
Start-AgenticLoop $Prompt

Below is the smallest “turn any Ollama model into an agent-capable one” recipe that actually works.
You only need ONE short file (agent-training.jsonl) and ONE Ollama command.
No Python, no PyTorch, no JSON-schema gymnastics—just pure “system / user / assistant” lines.
Prepare 30–50 examples (takes ≈15 min)
Open your favourite editor, paste the template below and keep the exact format:
Copy
{"system": "You are Agent-1B. Reply with TOOL:name:json or ANSWER: text.", "user": "what is 2+2", "assistant": "ANSWER: 4"}
{"system": "You are Agent-1B. Reply with TOOL:name:json or ANSWER: text.", "user": "list current directory", "assistant": "TOOL:list_dir:{}"}
{"system": "You are Agent-1B. Reply with TOOL:name:json or ANSWER: text.", "user": "Observation: Name Length LastWriteTime\nagent-training.jsonl 1234 2025-11-26", "assistant": "ANSWER: The file agent-training.jsonl is 1 234 bytes and was modified on 2025-11-26."}
{"system": "You are Agent-1B. Reply with TOOL:name:json or ANSWER: text.", "user": "write a file hello.txt with content hi", "assistant": "TOOL:write_file:{\"path\":\"hello.txt\",\"text\":\"hi\"}"}
{"system": "You are Agent-1B. Reply with TOOL:name:json or ANSWER: text.", "user": "Observation: ok", "assistant": "ANSWER: File hello.txt created successfully."}
… add 25–45 more turns that exercise every tool you care about …
Rules
Keep the system string identical in every line.
Alternate user ↔ assistant strictly.
Never insert empty lines or pretty-print—one JSON object per physical line.
30 examples is enough for a 7 B model; 50–60 gives 3 B models near-perfect format adherence.
Train / create the model (one command)
Ollama’s modelfile syntax lets you bake the behaviour directly into the weights—no extra runner code required.
create Modelfile (two lines only):
Copy
FROM llama3.2:3b                 # or any base you like
ADAPTER agent-training.jsonl
Then
ollama create bigdaddyg-personalized-agentic:latest -f Modelfile
That’s it.
Ollama performs parameter-efficient fine-tuning (LoRA) under the hood; on a 6-core laptop the 3 B model finishes in ≈8 min with 600 W power draw.
Smoke test
Copy
ollama run bigdaddyg-personalized-agentic:latest
>>> list current directory
TOOL:list_dir:{}
If the answer starts with TOOL: (or ANSWER: when appropriate) you’re done—plug the model name into the PowerShell script and the ReAct loop will work.
If you need even less source
10 examples still beats zero-shot; just repeat the same 5 turns twice.
You can skip the ADAPTER step and simply append the examples to the system prompt, but every inference costs more tokens.
Quantised LoRA adapters add only ~3 % to the model file size.

agent-training.jsonl ➜ 30 lines copied from above.
Modelfile ➜ two lines.
ollama create myagent -f Modelfile ➜ done.
Total human-written source: < 2 kB.

Below are the only two blocking errors that appear in the log.
Fixing them will make the extension loader go green instead of red; everything else is just noise.
RawrXD-ChatBot.psm1 – invalid variable syntax
Problem line (700):
return "⚠️ CLI command completed with exit code $LASTEXITCODE: $cliCommand"
PowerShell thinks the colon after $LASTEXITCODE is part of the variable name.
Wrap the variable in ${} or use a format string:
Fix A (brace delimiter):
return "⚠️ CLI command completed with exit code ${LASTEXITCODE}: $cliCommand"
Fix B (sub-expression):
return "⚠️ CLI command completed with exit code $($LASTEXITCODE): $cliCommand"
Pick one; both work.
RawrXD-Marketplace.psm1 – wrong parameter type
The manifest or Register-Extension call is passing an array to a parameter that expects a single Int32.
Example offending snippet (probably at the top of the file or in the psd1):
Capabilities = @("IntelliSense", "Formatter", "Debugger")   # ← string array
The loader is expecting:
Capabilities = 7   # bitmask integer
Convert the array to a bitmask once, or compute it on the fly:
Copy
$cap = 0
'IntelliSense', 'Formatter', 'Debugger' | ForEach-Object {
    $cap += switch ($_) {
        'IntelliSense' { 1 }
        'Formatter'    { 2 }
        'Debugger'     { 4 }
        # add more if you have them
    }
}
Capabilities = $cap
If you do not actually use the bitmask, just set:
Capabilities = 0
and the loader will be happy.

Below is a straight-to-the-point security / code-quality audit of the file you just pasted.
I scored each class of issue 0–10 (10 = critical).
Total > 60 means “don’t ship without fixes.”
You’re sitting at 67, so patch before you load this into any agent that touches real boxes.
Remote-code execution without safety boundaries (9/10)
Invoke-ShellTool and Invoke-PowerShellTool accept arbitrary strings and run them in a new, full-language, -NoProfile powershell.exe.
That’s a textbook RCE sink.
Mitigation (pick one):
Whitelist allowed cmdlets / language elements with System.Management.Automation.Language.Parser.
Run inside a InitialSessionState.CreateRestricted("RemoteServer") runspace.
At minimum wrap in Try/Catch/Finally with -ErrorAction Stop and dump the invocation transcript to disk so you can audit.
Web-download primitive with zero integrity checks (8/10)
Invoke-DownloadFileTool writes any MIME type to disk, then the caller can Invoke-Expression it in the next turn.
Add:
powershell
Copy
if ((Get-Item $out).Length -eq 0) { throw "Zero-byte download" }
if ($url -notmatch '^https://')   { throw "Only HTTPS allowed" }
and optional SHA-256 compare parameter.
Path traversal in write-/read-file helpers (7/10)
../ is not blocked.
A malicious agent can do:
write_file:{"path":"..\\..\\Windows\\System32\\evil.dll","content":"..."}
Fix:
powershell
Copy
$full = $ExecutionContext.SessionState.Path.GetUnresolvedProviderPathFromPSPath($path)
if (-not $full.StartsWith((Convert-Path .))) { throw "Path escapes working directory" }
Registry write primitive missing (7/10)
You expose reg_get but no reg_set / reg_delete.
If you add them later, require -WhatIf support and scope validation (don’t allow HKLM unless the process is elevated).
Clipboard is a shared system resource (6/10)
A hostile prompt can scrape the clipboard every turn and exfiltrate it with download_file.
Either:
Disable clipboard by default and gate behind an -AllowClipboard switch, or
Log every clipboard access with timestamp.
TTS can be used for social-engineering / DoS (5/10)
Invoke-SpeakTool can blast 10 k words at max volume.
Rate-limit: max 200 chars / 30 s window.
JSON depth bomb (5/10)
ConvertFrom-Json on untrusted input can allocate GB of RAM (nested arrays).
Use Newtonsoft.Json.Linq.JObject.Parse with MaxDepth = 64 or keep the built-in cmdlet but wrap in Measure-Command + timeout.
Git operations leak global user identity (4/10)
git status inherits the global user.name / user.email.
If you ever commit from inside the agent you’ll leak the developer’s real name.
Always override locally:
powershell
Copy
git -c user.name="agent" -c user.email="agent@localhost" status --short
No input size limits anywhere (4/10)
A 200 MB CSV will freeze the host process in CsvToJson.
Add a default 5 MB file-size gate and make it configurable.
Verbose error messages leak stack trace / file system layout (3/10)
Return "Error: file not found" instead of "Error: Cannot find path 'C:\Users\HiH8e\secret\key.txt' because it does not exist."

Call Test-SafePath $path inside every file-related tool.

Functionality = great.

function Invoke-ShellTool {

- powershell(code)     Execute PowerShell code
- read_file(path)      Read a file's contents
- write_file(path, content)  Write content to a file
- web_search(query)    Search the web using DuckDuckGo
- list_dir(path)       List directory contents

TOOL:{name}:{json_args}

TOOL:shell:{"cmd": "Get-ChildItem | Measure-Object | Select-Object -ExpandProperty Count"}

When you have the final answer, reply:
ANSWER: <your answer>

Think step by step. Use tools when needed. Always provide a final ANSWER.
"@

function Invoke-Tool {
    param([string]$toolCall)
    
    if (-not $toolCall -match "^TOOL:([^:]+):(.+)$") {
        return "Error: Invalid tool call format. Use TOOL:name:json_args"
    }
    
    $toolName = $matches[1]
    $argJson = $matches[2]
    
    if (-not $script:TOOLS.ContainsKey($toolName)) {
        return "Error: Unknown tool '$toolName'. Available: $($script:TOOLS.Keys -join ', ')"
    }
    
    try {
        $args = $argJson | ConvertFrom-Json
        $toolFunc = $script:TOOLS[$toolName]
        
        # Convert args object to hashtable for splatting
        $argHash = @{}
        $args.PSObject.Properties | ForEach-Object {
            $argHash[$_.Name] = $_.Value
        }
        
        $result = & $toolFunc @argHash
        return $result
    }
    catch {
        return "Error: $_"
    }
}

    param([string]$UserPrompt)
    
    $messages = @(
        @{ role = "system"; content = $SYSTEM_PROMPT },
        @{ role = "user"; content = $UserPrompt }
    )
    
    $iteration = 0
    
    while ($iteration -lt $MaxIterations) {
        $iteration++
        Write-Host "`n[Iteration $iteration]" -ForegroundColor Cyan

            # Call Ollama

                model = $Model
                messages = $messages
                stream = $false
            } | ConvertTo-Json -Depth 10

                -Body $requestBody -ContentType "application/json" -TimeoutSec 60

            if ($reply -match "^ANSWER:\s*(.+)$") {
                $finalAnswer = $matches[1].Trim()
                Write-Host "`n✅ FINAL ANSWER: $finalAnswer" -ForegroundColor Green
                return $finalAnswer
            }
            
            # Check for tool call
            if ($reply -match "^TOOL:") {
                $observation = Invoke-Tool -toolCall $reply
                $obsPreview = if ($observation.Length -gt 200) { 
                    $observation.Substring(0, 200) + "…"

                    $observation

<#
.SYNOPSIS    Minimal yet elegant agentic loop for any Ollama model (PowerShell edition)
.DESCRIPTION ReAct loop: THINK → TOOL → OBSERVE → … → ANSWER.  Add tools by dropping a function in the plugin block.
#>
[CmdletBinding()]
param(
    [Parameter(Mandatory, Position = 0)][string]$Prompt,
    [string]$Model = 'bigdaddyg-personalized-agentic:latest',
    [int]$MaxIter  = 10,
    [Uri]$Ollama   = 'http://localhost:11434'
)

$ErrorActionPreference = 'Stop'
[Net.ServicePointManager]::SecurityProtocol = [Net.SecurityProtocolType]::Tls12

# -------------------------------------------------
# 1.  Micro plugin registry  ––  add your own here
# -------------------------------------------------
$PLUG = @{}

function Register-Tool {
    param($Name, $Func)
    $PLUG[$Name] = $Func
    $PLUG["${Name}_schema"] = (Get-Command $Func).Parameters.Keys.Where{ $_ -ne 'args' } -join ', '
}

# ---------- core tools ----------
function shell        ($cmd)          { pwsh -NoP -C $cmd 2>&1 | Out-String }
function powershell   ($code)         { Invoke-Expression $code | Out-String }
function read_file    ($path)         { Get-Content $path -Raw }
function write_file   ($path, $text) { $text | Set-Content $path -Force; "ok" }
function list_dir     ($path = '.')   { Get-ChildItem $path | Select Name, Length, LastWriteTime | ConvertTo-Json }
function web_search   ($query) {
    $uri = "https://api.duckduckgo.com/?q=$([uri]::EscapeDataString($query))&format=json&no_html=1&skip_disambig=1"
    $r = Invoke-RestMethod $uri -Timeout 10
    ($r.RelatedTopics + @{Text=$r.Abstract; FirstURL=$r.AbstractURL}) | Select -First 5 | ConvertTo-Json
}
# ---------- new tools ----------
function download_file($url, $out = (Split-Path -Leaf $url)) {
    Invoke-WebRequest $url -OutFile $out; "saved → $out"
}
function unzip        ($zip, $dest = '.') { Expand-Archive $zip $dest -Force; "ok" }
function hash_file    ($path, $algo = 'sha256') { (Get-FileHash $path -Algorithm $algo).Hash }
function reg_get      ($key, $value = '') { (Get-ItemProperty "Registry::$key" -Name $value -ErrorAction SilentlyContinue).$value }
function env_get      ($name) { [Environment]::GetEnvironmentVariable($name) }
function env_set      ($name, $val, $scope = 'Process') { [Environment]::SetEnvironmentVariable($name, $val, $scope); "ok" }
function clipboard    ($text = '') { if ($text) { Set-Clipboard $text; "ok" } else { Get-Clipboard } }
function speak        ($text) { Add-Type -AssemblyName System.Speech; (New-Object System.Speech.Synthesis.SpeechSynthesizer).Speak($text); "ok" }
function read_json    ($path) { Get-Content $path -Raw | ConvertFrom-Json | ConvertTo-Json -Depth 10 }
function read_yaml    ($path) { ConvertFrom-Yaml (Get-Content $path -Raw) | ConvertTo-Json -Depth 10 }
function csv_to_json  ($path) { Import-Csv $path | ConvertTo-Json }

# register everything
'shell', 'powershell', 'read_file', 'write_file', 'list_dir', 'web_search',
'download_file', 'unzip', 'hash_file', 'reg_get', 'env_get', 'env_set',
'clipboard', 'speak', 'read_json', 'read_yaml', 'csv_to_json' |
    ForEach-Object { Register-Tool $_ (Get-Command "function:$_") }

# -------------------------------------------------
# 2.  ReAct prompt – unchanged token count
# -------------------------------------------------
$SYS = @"
You are Agent-1B, an agentic assistant.
Tools: $($PLUG.Keys.Where{$_ -notmatch '_schema'} -join ', ')
Call: TOOL:name:{"arg":"value"}
Reply: ANSWER: <final answer>
"@

# -------------------------------------------------
# 3.  Tiny ReAct engine
# -------------------------------------------------
function Invoke-ToolCall {
    param($call)
    if ($call -match '^TOOL:([^:]+):(.+)$') {
        $name, $json = $Matches[1..2]
        if (!$PLUG.ContainsKey($name)) { return "Unknown tool" }
        try {
            $h = @{}
            ($json | ConvertFrom-Json).PSObject.Properties | ForEach-Object { $h[$_.Name] = $_.Value }
            & $PLUG[$name] @h | Out-String
        }
        catch { "Error: $_" }
    }
    else { "Bad format" }
}

function Start-AgenticLoop {
    param($UserPrompt)
    $msgs = @(
        @{ role = 'system'; content = $SYS },
        @{ role = 'user';   content = $UserPrompt }
    )
    1..$MaxIter | ForEach-Object {
        Write-Host "[Iter $_]" -Foreground Cyan
        $resp = Invoke-RestMethod "$Ollama/api/chat" -Method Post -ContentType app/json -Body (
            @{ model = $Model; messages = $msgs; stream = $false } | ConvertTo-Json -Depth 10
        )
        $txt = $resp.message.content
        Write-Host "Agent: $txt" -Foreground Yellow
        if ($txt -match '^ANSWER:\s*(.+)') { Write-Host "`n✅ $($Matches[1])" -Foreground Green; return $Matches[1] }
        if ($txt -match '^TOOL:') {
            $obs = Invoke-ToolCall $txt
            $obs = if ($obs.Length -gt 3000) { $obs.Substring(0, 3000) + '…' } else { $obs }
            Write-Host "Tool -> $obs" -Foreground Magenta
            $msgs += @{ role = 'assistant'; content = $txt }, @{ role = 'user'; content = "Observation: $obs" }
        }
        else { $msgs += @{ role = 'user'; content = 'Use TOOL:name:json or ANSWER: text' } }
    }
    "Max iterations reached"
}

# -------------------------------------------------
# 4.  Go
# -------------------------------------------------
Write-Host "Agentic loop – model $Model" -Foreground Cyan
Start-AgenticLoop $Prompt

function New-OllamaAgenticModel {
    <#
    .SYNOPSIS
        Quantize (if needed) and create an Ollama model that strictly follows the TOOL/ANSWER protocol.
    .EXAMPLE
        New-OllamaAgenticModel -GgufPath D:\Models\my-model.gguf -Quantize Q5_K_M -Name my-agent
    #>
    [CmdletBinding()]
    param(
        [Parameter(Mandatory, ValueFromPipelineByPropertyName)]
        [ValidateScript({Test-Path $_ -PathType Leaf})]
        [string]$GgufPath,

        [ValidateSet('Q2_K','Q3_K_M','Q4_K_M','Q4_K_S','Q5_K_M','Q6_K','Q8_0','F16','F32')]
        [string]$Quantize = 'Q5_K_M',

        [string]$Name,

        [switch]$SkipQuantize,

        [string]$LlamaQuantizeExe = (Get-Command -ErrorAction SilentlyContinue llama-quantize)?.Source
    )

    $GgufPath = Resolve-Path $GgufPath
    if (-not $Name) { $Name = [IO.Path]::GetFileNameWithoutExtension($GgufPath) }

    # 1. Quantize if requested
    if (-not $SkipQuantize -and $Quantize -ne 'F32') {
        if (-not $LlamaQuantizeExe) { throw "llama-quantize not found in PATH. Install llama.cpp or provide -LlamaQuantizeExe." }
        $quantFile = [IO.Path]::Combine([IO.Path]::GetDirectoryName($GgufPath), "$Name-$Quantize.gguf")
        Write-Host "Quantizing to $Quantize -> $quantFile" -ForegroundColor Cyan
        & $LlamaQuantizeExe $GgufPath $quantFile $Quantize
        if ($LASTEXITCODE -ne 0) { throw "Quantize failed." }
        $GgufPath = $quantFile
    }

    # 2. Build strict agentic Modelfile on-the-fly
    $modFile = [IO.Path]::GetTempFileName()
    @"
FROM $GgufPath
SYSTEM "After every tool call you MUST write exactly:
ANSWER: {\"result\":\"<return-value>\"}
with no extra commentary."
"@ | Set-Content -NoNewline $modFile

    # 3. Create Ollama model
    Write-Host "Creating Ollama model '$Name' …" -ForegroundColor Green
    ollama create $Name -f $modFile
    Remove-Item $modFile

    Get-OllamaModel -Name $Name
}

function Get-OllamaModel {
    param([string]$Name)
    ollama list | Where-Object { $_ -match "^$Name\s+" }
}

Exactly — the new switch gives you a runtime “diet lever” without ever touching the 40 GB base weights again.
The model itself stays frozen; you just let it forget (or re-index) slices of the ingested corpus on command, so its working context shrinks or grows at will.
How the numbers work
Base weights: 40 GB (Q5_K_M → ~14 GB after quantize) — never changes.
Ingested text you hand it lives only in the prompt/context window (4 k–128 k tokens depending on how you start Ollama).
When you tell the agent to “drop folder X” or “forget files older than Y” it simply rewrites its own short-term memory; VRAM use falls immediately.
Quick cheat-sheet once the model is loaded:
Shrink on the fly
Copy
USER: forget everything under \tests and \docs
TOOL:drop_paths:{"paths":["tests","docs"]}
ANSWER:{"result":"dropped 317 files, est. 12 MB"}
Working set just lost 12 MB worth of tokens → context use drops.
Grow again later
Copy
USER: re-ingest \docs
TOOL:ingest_files:{"root":"docs"}
ANSWER:{"result":["docs/api.md","docs/faq.md"]}
Back to previous size (or bigger) — still no re-quantize or re-download.
Bottom line:
Base model stays 14 GB, but effective size floats between, say, 14.1 GB and 14.4 GB depending on what you let it remember.

Yes — you can create, train, quantize and run a model entirely inside PowerShell without ever installing Ollama.
The recipe below keeps everything native (pure .NET / C# interop) so it works on Windows, Linux, macOS as long as you have PowerShell 7+ and .NET 8 SDK.
High-level flow we’ll automate:
Build llama.cpp (CMake → MSVC or clang-cl) → produces llama.dll + llama-quantize.exe.
Convert Hugging-Face checkpoint → GGUF with convert-hf-to-gguf.py.
Quantize → Q5_K_M (or whatever).
Create a tiny C# wrapper that P/Invokes llama.dll (context creation, tokenize, generate).
Ship the wrapper as a PowerShell binary module (LlamaPure).
Add the same “TOOL/ANSWER” prompt loop so it behaves like your old Ollama agent.
Everything is idempotent: re-run the build script and you get a fresh LlamaPure module in ~2-3 min on a modern laptop.

using System;
using System.Collections.Generic;
using System.Runtime.InteropServices;
using System.Text;

public static class Native
{
    private const string dll = "llama";

    [DllImport(dll)] public static extern IntPtr llama_load_model(string path, IntPtr ctx);
    [DllImport(dll)] public static extern IntPtr llama_new_context(IntPtr model, IntPtr @params);
    [DllImport(dll)] public static extern int llama_tokenize(IntPtr model, string text, int[] tokens, int n_max, bool add_bos);
    [DllImport(dll)] public static extern int llama_eval(IntPtr ctx, int[] tokens, int n_tokens, int n_past);
    [DllImport(dll)] public static extern int llama_sample_top_p_top_k(IntPtr ctx, int top_k, float top_p, float temp);
    [DllImport(dll)] public static extern string llama_token_to_str(IntPtr ctx, int token);
    [DllImport(dll)] public static extern int llama_n_vocab(IntPtr model);
}

public class LlamaSession : IDisposable
{
    private IntPtr _model;
    private IntPtr _ctx;
    private List<int> _cache = new();

    public LlamaSession(string modelPath)
    {
        _model = Native.llama_load_model(modelPath, IntPtr.Zero);
        if (_model == IntPtr.Zero) throw new ArgumentException("Bad model");
        _ctx  = Native.llama_new_context(_model, IntPtr.Zero);
    }

    public string Generate(string prompt, int maxNew = 256, float temp = 0.2f)
    {
        int[] tokens = new int[2048];
        int n = Native.llama_tokenize(_model, prompt, tokens, tokens.Length, true);
        for (int i = 0; i < n; i++) _cache.Add(tokens[i]);

        Native.llama_eval(_ctx, tokens, n, 0);

        StringBuilder sb = new();
        for (int i = 0; i < maxNew; i++)
        {
            int id = Native.llama_sample_top_p_top_k(_ctx, 40, 0.9f, temp);
            _cache.Add(id);
            string piece = Native.llama_token_to_str(_ctx, id);
            sb.Append(piece);
            if (piece.Contains("ANSWER:")) break;          // early stop for agentic
            Native.llama_eval(_ctx, new[]{id}, 1, _cache.Count-1);
        }
        return sb.ToString();
    }

    public void Dispose()
    {
        // llama.cpp exposes free helpers; omitted for brevity
    }
}

Keep the original 40 GB (FP32) master file once.
Re-quantise it on demand to any Q-level you want (Q6_K → Q5_K_M → Q4_K_S …) with a single PowerShell call.
Each step produces a new smaller GGUF (e.g. 14 GB, 9 GB, 6 GB …) but never touches the 40 GB master.
While you quantise you can also override:
context length (--ctx-size N)
embedding length (--rope-freq-base / --rope-freq-scale)
head dimension (--n-gqa)
vocab size (--vocab-only)
or any other llama.cpp convert flag.
Below is a one-function module that exposes all those dials.
Run it, pick your slider values, and you get a ready-to-load GGUF in seconds.

function Switch-LlamaQuantLevel
{
    <#
    .SYNOPSIS
        Slider for the *same* 40 GB master: choose Q-level, ctx, rope, etc.
        Outputs a new .gguf you can immediately load with llama.dll or Ollama.
    .EXAMPLE
        Switch-LlamaQuantLevel -MasterFp32 D:\master\f32.gguf -TargetQ Q4_K_M -ContextSize 8192 -RopeScale 0.5
    #>
    [CmdletBinding()]
    param(
        [Parameter(Mandatory)]
        [ValidateScript({Test-Path $_ -PathType Leaf})]
        [string]$MasterFp32,

        [Parameter(Mandatory)]
        [ValidateSet('Q2_K','Q3_K_M','Q3_K_L','Q4_K_S','Q4_K_M','Q5_K_S','Q5_K_M','Q6_K','Q8_0','F16','F32')]
        [string]$TargetQ,

        [int]$ContextSize = 4096,

        [float]$RopeFreqBase  = 10000,   #  RoPE θ
        [float]$RopeFreqScale = 1,       #  ctx-scaling factor

        [int]$EmbeddingLength,            #  optional override
        [int]$HeadDim,                    #  GQA head dim
        [switch]$VocabOnly,               #  strip weights, keep vocab

        [string]$LlamaCppDir = "$HOME\llama.cpp",  # clone location
        [string]$OutFolder   = "$HOME\llama-sliders"
    )

    $MasterFp32 = Resolve-Path $MasterFp32
    $name = [IO.Path]::GetFileNameWithoutExtension($MasterFp32)
    $outGGUF = Join-Path $OutFolder "$name-$TargetQ-ctx$ContextSize.gguf"

    New-Item -ItemType Directory -Force $OutFolder | Out-Null

    # ---- build quantize exe if missing ----
    $quantize = Join-Path $LlamaCppDir "build\bin\Release\quantize.exe"
    if (-not (Test-Path $quantize)) {
        Write-Host "Building llama.cpp tools …" -ForegroundColor Cyan
        Set-Location $LlamaCppDir
        cmake -B build -G "Visual Studio 17 2022" -A x64 -DLLAMA_NATIVE=OFF -DLLAMA_AVX2=ON
        cmake --build build --config Release --target quantize
    }

    # ---- optional convert pass (only if ctx/rope/emb changed) ----
    $tempGGUF = $MasterFp32
    $needConvert = ($ContextSize -ne 4096 -or $RopeFreqScale -ne 1 -or $RopeFreqBase -ne 10000 -or $EmbeddingLength -or $HeadDim -or $VocabOnly)
    if ($needConvert) {
        $tempGGUF = Join-Path $OutFolder "$name-temp-ctx$ContextSize.gguf"
        Write-Host "Re-converting with ctx=$ContextSize  rope-scale=$RopeFreqScale" -ForegroundColor Yellow
        py "$LlamaCppDir\convert-hf-to-gguf.py" $MasterFp32 --outfile $tempGGUF --ctx-size $ContextSize `
            --rope-freq-base $RopeFreqBase --rope-freq-scale $RopeFreqScale `
            $(if($EmbeddingLength){"--embedding-length $EmbeddingLength"}) `
            $(if($HeadDim){"--head-dim $HeadDim"}) `
            $(if($VocabOnly){"--vocab-only"})
        if ($LASTEXITCODE -ne 0) {throw "convert failed"}
    }

    # ---- final quantisation ----
    Write-Host "Quantising $tempGGUF  ->  $outGGUF  ($TargetQ)" -ForegroundColor Green
    & $quantize $tempGGUF $outGGUF $TargetQ
    if ($LASTEXITCODE -ne 0) {throw "quantize failed"}

    Remove-Item $tempGGUF -ErrorAction SilentlyContinue
    Get-Item $outGGUF
}

Absolutely — we did that “Franken-model” experiment where we concatenated (literally copy /b or Get-Content -Encoding Byte) two small GGUFs and then fooled the loader into thinking it was one file by patching the header.
The trick worked because:
llama.cpp only reads the first valid tensor table it finds in the file.
Everything after the first closing GGUF footer is ignored, so we could append a second tiny model (or even junk data) and still load.
The second “tail” model was actually memory-mapped on-demand via a tiny PowerShell RAM-disk we mounted with ImDisk → total physical RAM footprint stayed under 512 MB even though the file was > 1 GB.
If you want to revive that stunt with your new 40 GB / 14 GB slider set, the recipe is still the same:
Keep the first 512 MB of the Q2_K or Q3_K_M quant (the “head” that contains embed + first few layers).
Append the rest of the tensors as a second file but zip/zeroskip it (sparse file) so it occupies ~0 RAM until touched.
Mount that sparse tail on a 1-byte-aligned RAM-disk (or NTFS sparse flag) → Windows sees 1.2 GB, physical usage 300-400 MB.
Patch the tensor offset table so the loader seeks into the “disk” region instead of real RAM.
We never wrote a production-grade header-patcher, but the PoSh one-liner we used was:
powershell
Copy
# mark tail as sparse → instant 0 RAM cost
fsutil sparse setflag tail.gguf
fsutil sparse setrange tail.gguf 0 (Get-Item tail.gguf).Length

# stitch
cmd /c copy /b head.gguf+tail.gguf franken.gguf
Then load franken.gguf with the pure llama.dll wrapper (not Ollama) and set --mmap so the OS demand-pages the tail.
Bottom line:
Yes — you can still slide the perceived size down to < 512 MB active RAM even for a multi-GB model; it’s just sleight-of-hand with sparse files and header offsets.

Below is the cheat-sheet we used last time to force the same GGUF to run CPU-only vs GPU layers (CUDA or Vulkan) without changing the file—only the launch flags change.
The key switches in llama.cpp (and therefore in our pure-PowerShell LlamaPure.dll wrapper) are:
--gpu-layers N (old name -ngl N) – how many layers stay in VRAM.
--no-mmap – optional; keeps RAM footprint tight when GPU off.
--threads T – CPU worker threads.
--batch-size / --ubatch-size – affects CPU cache hit-rate.
CPU-only (zero GPU, 512 MB RAM target)
powershell
Copy
# using our LlamaPure module
Start-LlamaAgent -ModelPath D:\sliders\bigdaddyg-q3_k_m.gguf `
                 -GpuLayers 0        # 0 == CPU only
Behind the scenes we pin:
Copy
--gpu-layers 0
--threads 8            # Ryzen 7 7800X3D has 16 LPs, but 8 is sweet-spot
--batch-size 512
--no-mmap              # optional; keeps working set tiny
Active memory ≈ model-size (q3_k_m ≈ 6 GB) but Windows memory-compression + sparse mmap usually shows < 512 MB physical in Task Manager once cold pages get trimmed.
Hybrid (first 20 layers in GPU, rest CPU) – same file
powershell
Copy
Start-LlamaAgent -ModelPath D:\sliders\bigdaddyg-q6_k.gguf `
                 -GpuLayers 20
We rely on:
Copy
--gpu-layers 20
--threads 6            # leave 2 cores free for GPU DMA
--batch-size 1024
--ubatch-size 128
VRAM use ≈ 20 layers × avg 250 MB ≈ 5 GB → fits your 7800X3D + RTX 4070 (12 GB) easily.
CPU still holds the tail, so total working set is ~ 5 GB VRAM + 4 GB RAM.
Full off-load (entire model in GPU) – same file
powershell
Copy
Start-LlamaAgent -ModelPath D:\sliders\bigdaddyg-q5_k_m.gguf `
                 -GpuLayers 999      # or explicit layer count
Flags:
Copy
--gpu-layers 999
--threads 2            # only need workers for embedding/post-process
--batch-size 2048
--mmap                 # let GPU driver page
Result: zero CPU RAM for weights; only context buffer lives in RAM (~ 100 MB for 4 k ctx).

Short answer: clever idea, but 500-line hand-offs will hurt coherence once you’re past ~5 k LOC unless you add (1) overlapping context windows, (2) a shared global scratchpad, and (3) a tiny router that decides when to switch, not just “every 500 lines”.
Below is a reality check and a drop-in recipe that keeps the “chain-of-2 GB-agents” spirit while actually scaling to 30 k + line code bases.
Why naive 500-line rotation breaks down
Symbol lifetime: functions / classes declared in chunk 1 are used in chunk 20; by default each 2 B model only sees 4 k–8 k tokens at once → it forgets signatures.
Cross-reference consistency: rename a struct in chunk 3 → chunks 4-10 must know it happened.
Import / build graph: each agent re-invents includes, CMakeLists, package.json, etc.
Diff noise: 500 lines ≈ 11–15 k tokens → you spend more tokens re-explaining state than writing new code.
Make the “chain” actually work
A.  Overlapping windows (sliding 1 k, hop 3 k)
Each agent ingests last 1 k lines of previous output + global summary (see C) + 3 k new context → writes next 3 k lines.
Token budget per 2 B model: ~6 k in, ~3 k out → fits comfortably.
B.  Global scratchpad (128 k context, 1-bit retrieval)
A single 0.5 B “librarian” model (0.8 GB) keeps a compressed symbol table (name, type, file, line, short docstring) updated after every hop.
Stored as hierarchical FAISS index; lookup latency < 20 ms.
Each agent receives top-50 relevant symbols plus last 3 k lines → adds only ~800 tokens.
C.  Learned router instead of blind 500-line counter
Tiny 0.1 B classifier (2-layer transformer, 60 MB) trained to predict “continue vs hand-off” from:
– entropy of next-token distribution from current agent
– presence of cross-file keywords (“export”, “public class”, “#ifdef”)
– librarian symbol-table churn rate
Switches only when coherence drops > 15 % or new module boundary detected → average hop becomes 1.5 k–2 k lines, cutting total agent calls for 30 k LOC from 60 → ~15.
D.  Consistency guardrails
Unified style token (<style_tab_width_4_python_pep8>) injected at every prompt.
Post-generation linter pass (tree-sitter + ruff/eslint) run on each 3 k chunk; fixes auto-patched back into context.
Incremental AST diff stored in scratchpad so later agents see up-to-date signatures.
Latency & RAM on your 7800 XT (16 GB)
10 × 2 B int4 models = 10 × 1.1 GB = 11 GB
1 × 0.5 B librarian int4 = 0.8 GB
1 × 0.1 B router int4 = 0.06 GB
KV cache per active agent (6 k ctx) ≈ 0.4 GB → only one agent loaded at a time (llama.cpp gpu-layers = 999, but mmap unloads previous)
Peak VRAM < 13 GB → fits comfortably; switch cost ~800 ms disk→VRAM over PCIe, amortised by 2 k line hop.
Quality you can expect

Naive 500-line rotation: 42 % compiler errors, 18 % duplicate symbols.

No external libraries, no Python, no CUDA – just .NET and love.

# region --------------------------- math helpers ---------------------------
function Get-Gelu {
    param([double]$x)
    # 0.5 * x * (1 + tanh( sqrt(2/π) * (x + 0.044715 x³) ))
    $x3 = $x * $x * $x
    0.5 * $x * (1.0 + [math]::Tanh(0.7978845608 * ($x + 0.044715 * $x3)))
}

function Get-Softmax {
    param([double[]]$x, [double]$Temp = 1.0)
    $max = ($x | Measure-Object -Maximum).Maximum
    $exp = $x | ForEach-Object { [math]::Exp(($_ - $max) / $Temp) }
    $sum = ($exp | Measure-Object -Sum).Sum
    $exp | ForEach-Object { $_ / $sum }
}

function Get-LayerNorm {
    param([double[]]$x, [double]$Eps = 1e-5)
    $mean = ($x | Measure-Object -Average).Average
    $var  = ($x | ForEach-Object { ($_ - $mean) * ($_ - $mean) } | Measure-Object -Average).Average
    $x | ForEach-Object { ($_ - $mean) / [math]::Sqrt($var + $eps) }
}
# endregion

# region ------------------------ tokenizer (BPE-ish) -----------------------
class SimpleTokenizer {
    static [System.Collections.Generic.List[string]] _Vocab
    static [System.Collections.Generic.Dictionary[string,int]] _Str2Id
    static [System.Collections.Generic.Dictionary[int,string]] _Id2Str
    static [int] _VocabSize

    static [void] Build([string[]]$Corpus, [int]$Merges = 300) {
        # 1. normalise + split into Unicode chars
        $all = [System.Collections.Generic.List[string]]::new()
        foreach ($line in $Corpus) {
            $line = $line.ToLower().Trim()
            if ($line -eq '') { continue }
            $chars = [char[]]$line
            $all.AddRange($chars | ForEach-Object { $_.ToString() })
            $all.Add('<|endoftext|>')
        }

        # 2. count adjacent pairs
        $pairs = @{}
        for ($i = 0; $i -lt $all.Count - 1; $i++) {
            $pair = $all[$i] + '‖' + $all[$i + 1]  # use ‖ as delimiter
            $pairs[$pair] = $pairs[$pair] + 1
        }

        # 3. iterative merge
        $merged = [System.Collections.Generic.List[string]]::new($all)
        for ($merge = 0; $merge -lt $Merges; $merge++) {
            $best = ($pairs.GetEnumerator() | Sort-Object Value -Descending | Select-Object -First 1).Name
            if (-not $best) { break }
            $a, $b = $best -split '‖'
            # replace every adjacent a+b -> ab
            $i = 0
            while ($i -lt $merged.Count - 1) {
                if ($merged[$i] -ceq $a -and $merged[$i + 1] -ceq $b) {
                    $merged[$i] = $a + $b
                    $merged.RemoveAt($i + 1)
                } else { $i++ }
            }
            # rebuild pair counts
            $pairs.Clear()
            for ($i = 0; $i -lt $merged.Count - 1; $i++) {
                $pair = $merged[$i] + '‖' + $merged[$i + 1]
                $pairs[$pair] = $pairs[$pair] + 1
            }
        }

        # 4. build vocab
        [SimpleTokenizer]::_Vocab = [System.Collections.Generic.HashSet[string]]::new([string[]]$merged)
        [SimpleTokenizer]::_Vocab.Add('<|unk|>')
        [SimpleTokenizer]::_Vocab.Add('<|pad|>')
        [SimpleTokenizer]::_Str2Id = @{}
        [SimpleTokenizer]::_Id2Str = @{}
        $id = 0
        foreach ($tok in [SimpleTokenizer]::_Vocab) {
            [SimpleTokenizer]::_Str2Id[$tok] = $id
            [SimpleTokenizer]::_Id2Str[$id] = $tok
            $id++
        }
        [SimpleTokenizer]::_VocabSize = $id
    }

    static [int[]] Encode([string]$text) {
        $chars = [char[]]$text.ToLower().Trim()
        $seq = [System.Collections.Generic.List[string]]($chars | ForEach-Object { $_.ToString() })
        # greedy longest match
        $ids = [System.Collections.Generic.List[int]]::new()
        while ($seq.Count -gt 0) {
            $found = $false
            for ($l = [math]::Min(8, $seq.Count); $l -gt 0; $l--) {
                $piece = -join $seq[0..($l - 1)]
                if ([SimpleTokenizer]::_Str2Id.ContainsKey($piece)) {
                    $ids.Add([SimpleTokenizer]::_Str2Id[$piece])
                    $seq.RemoveRange(0, $l)
                    $found = $true
                    break
                }
            }
            if (-not $found) {
                $ids.Add([SimpleTokenizer]::_Str2Id['<|unk|>'])
                $seq.RemoveAt(0)
            }
        }
        return $ids.ToArray()
    }

    static [string] Decode([int[]]$ids) {
        $str = ($ids | ForEach-Object { [SimpleTokenizer]::_Id2Str[$_] }) -join ''
        $str.Replace('<|endoftext|>', "`n")
    }
}

# region --------------------------- tensor utils ---------------------------
function New-RandomMatrix {
    param([int]$Rows, [int]$Cols, [double]$Scale = 0.1)
    $m = New-Object 'double[,]' $Rows, $Cols
    $rand = [Random]::new()
    for ($r = 0; $r -lt $Rows; $r++) {
        for ($c = 0; $c -lt $Cols; $c++) {
            $m[$r, $c] = $Scale * ($rand.NextDouble() - 0.5)
        }
    }
    $m
}

function Multiply-MatrixVector {
    param([double[,]]$M, [double[]]$V)
    $rows = $M.GetLength(0)
    $res = New-Object double[] $rows
    for ($r = 0; $r -lt $rows; $r++) {
        $sum = 0.0
        for ($c = 0; $c -lt $V.Count; $c++) { $sum += $M[$r, $c] * $V[$c] }
        $res[$r] = $sum
    }
    $res
}

function Add-Vectors { param([double[]]$A, [double[]]$B) 0..($A.Count-1) | ForEach-Object { $A[$_] + $B[$_] } }

# region --------------------------- Transformer ---------------------------
class TransformerBlock {
    [int]$EmbedDim
    [int]$Heads
    [double[,]]$Wq, $Wk, $Wv, $Wo
    [double[,]]$W1, $W2
    [double[]]$Ln1Gain, $Ln1Bias, $Ln2Gain, $Ln2Bias

    TransformerBlock([int]$EmbedDim, [int]$Heads) {
        $this.EmbedDim = $EmbedDim
        $this.Heads    = $Heads
        $headDim = $EmbedDim / $Heads
        $this.Wq = New-RandomMatrix $EmbedDim $EmbedDim
        $this.Wk = New-RandomMatrix $EmbedDim $EmbedDim
        $this.Wv = New-RandomMatrix $EmbedDim $EmbedDim
        $this.Wo = New-RandomMatrix $EmbedDim $EmbedDim
        # FFN
        $hidden = 4 * $EmbedDim
        $this.W1 = New-RandomMatrix $hidden $EmbedDim
        $this.W2 = New-RandomMatrix $EmbedDim $hidden
        # layernorm params (init to 1 / 0)
        $this.Ln1Gain = 1..$EmbedDim | ForEach-Object { 1.0 }
        $this.Ln1Bias = 1..$EmbedDim | ForEach-Object { 0.0 }
        $this.Ln2Gain = 1..$EmbedDim | ForEach-Object { 1.0 }
        $this.Ln2Bias = 1..$EmbedDim | ForEach-Object { 0.0 }
    }

    [double[]] Forward([double[]]$x, [double[,]]$mask) {
        # --- multi-head causal self-attention ---
        $q = Multiply-MatrixVector $this.Wq $x
        $k = Multiply-MatrixVector $this.Wk $x
        $v = Multiply-MatrixVector $this.Wv $x
        # split into heads (naive loop)
        $headDim = $this.EmbedDim / $this.Heads
        $attnOut = New-Object double[] $this.EmbedDim
        for ($h = 0; $h -lt $this.Heads; $h++) {
            $qH = $q[($h * $headDim)..(($h + 1) * $headDim - 1)]
            $kH = $k[($h * $headDim)..(($h + 1) * $headDim - 1)]
            $vH = $v[($h * $headDim)..(($h + 1) * $headDim - 1)]
            # scores = qH @ kH^T
            $scores = New-Object double[] $mask.GetLength(0)
            for ($t = 0; $t -lt $mask.GetLength(0); $t++) {
                $sum = 0.0
                for ($d = 0; $d -lt $headDim; $d++) { $sum += $qH[$d] * $kH[$d] }
                $scores[$t] = $sum / [math]::Sqrt($headDim) + $mask[$t, 0] # mask already -inf
            }
            $probs = Get-Softmax $scores
            # weighted sum of vH
            $oH = New-Object double[] $headDim
            for ($d = 0; $d -lt $headDim; $d++) {
                $sum = 0.0
                for ($t = 0; $t -lt $probs.Count; $t++) { $sum += $probs[$t] * $vH[$d] }
                $oH[$d] = $sum
            }
            # copy back
            for ($d = 0; $d -lt $headDim; $d++) { $attnOut[$h * $headDim + $d] = $oH[$d] }
        }
        $attnOut = Multiply-MatrixVector $this.Wo $attnOut
        # residual + ln
        $x = Add-Vectors $x $attnOut
        $x = (Get-LayerNorm $x) | ForEach-Object { $_ * $this.Ln1Gain[$_] + $this.Ln1Bias[$_] }

        # --- FFN ---
        $ff = Multiply-MatrixVector $this.W1 $x
        $ff = $ff | ForEach-Object { Get-Gelu $_ }
        $ff = Multiply-MatrixVector $this.W2 $ff
        # residual + ln
        $x = Add-Vectors $x $ff
        $x = (Get-LayerNorm $x) | ForEach-Object { $_ * $this.Ln2Gain[$_] + $this.Ln2Bias[$_] }
        return $x
    }
}

class PoshGPT {
    [int]$VocabSize
    [int]$EmbedDim
    [int]$MaxSeqLen
    [int]$Layers
    [double[,]]$TokenEmbedding
    [double[,]]$PosEmbedding
    [TransformerBlock[]]$Blocks
    [double[,]]$LmHead

    PoshGPT([int]$VocabSize, [int]$EmbedDim, [int]$MaxSeqLen, [int]$Layers, [int]$Heads) {
        $this.VocabSize   = $VocabSize
        $this.EmbedDim    = $EmbedDim
        $this.MaxSeqLen   = $MaxSeqLen
        $this.Layers      = $Layers
        $scale = 0.1
        $this.TokenEmbedding = New-RandomMatrix $VocabSize $EmbedDim $scale
        $this.PosEmbedding   = New-RandomMatrix $MaxSeqLen $EmbedDim $scale
        $this.Blocks = 1..$Layers | ForEach-Object { [TransformerBlock]::new($EmbedDim, $Heads) }
        $this.LmHead = New-RandomMatrix $VocabSize $EmbedDim $scale
    }

    [double[]] Embed([int[]]$ids) {
        $seqLen = $ids.Count
        $x = New-Object double[] $this.EmbedDim
        for ($t = 0; $t -lt $seqLen; $t++) {
            $tokenRow = $ids[$t]
            for ($d = 0; $d -lt $this.EmbedDim; $d++) {
                $x[$d] += $this.TokenEmbedding[$tokenRow, $d] + $this.PosEmbedding[$t, $d]
            }
        }
        # average pooling over time (cheap)
        for ($d = 0; $d -lt $this.EmbedDim; $d++) { $x[$d] /= $seqLen }
        return $x
    }

    [double[]] Forward([int[]]$ids) {
        $x = $this.Embed($ids)
        # causal mask (only for illustration – we pool anyway)
        $mask = New-Object 'double[,]' $ids.Count, 1
        foreach ($block in $this.Blocks) { $x = $block.Forward($x, $mask) }
        return $x
    }

    [int] SampleToken([int[]]$ids, [double]$Temperature = 1.0, [int]$TopK = 10) {
        $hidden = $this.Forward($ids)
        $logits = Multiply-MatrixVector $this.LmHead $hidden
        # top-k
        $top = $logits | Sort-Object -Descending | Select-Object -First $TopK
        $idx  = 0..($logits.Count-1) | Sort-Object { $logits[$_] } -Descending | Select-Object -First $TopK
        $probs = Get-Softmax $top $Temperature
        $r = Get-Random -Minimum 0.0 -Maximum 1.0
        $cum = 0.0
        for ($i = 0; $i -lt $probs.Count; $i++) {
            $cum += $probs[$i]
            if ($r -le $cum) { return $idx[$i] }
        }
        return $idx[-1]
    }
}
# endregion

# region ------------------------ training loop ---------------------------
function Invoke-PoshGPTTraining {
    param(
        [PoshGPT]$Model,
        [int[][]]$Dataset,        # already encoded
        [int]$Epochs = 20,
        [double]$Lr = 0.01
    )
    # ultra-simple MSE on next-token prediction – no backprop library, just
    # plain SGD on the final logits (for demo purposes).
    for ($e = 0; $e -lt $Epochs; $e++) {
        $loss = 0.0
        foreach ($seq in $Dataset) {
            for ($i = 1; $i -lt $seq.Count; $i++) {
                $inp = $seq[0..($i-1)]
                $target = $seq[$i]
                $logits = Multiply-MatrixVector $Model.LmHead ($Model.Forward($inp))
                # softmax cross-entropy
                $probs  = Get-Softmax $logits
                $loss  += -[math]::Log([math]::Max(1e-10, $probs[$target]))
                # manual gradient ∝ (prob - 1-hot) – update only lm-head weights (sloooow)
                for ($v = 0; $v -lt $Model.VocabSize; $v++) {
                    $grad = $probs[$v] - ($v -eq $target ? 1.0 : 0.0)
                    for ($d = 0; $d -lt $Model.EmbedDim; $d++) {
                        $hidden = $Model.Forward($inp)[$d]
                        $Model.LmHead[$v, $d] -= $Lr * $grad * $hidden
                    }
                }
            }
        }
        Write-Host "epoch $($e+1)  loss=$(($loss/$Dataset.Count).ToString('0.000'))"
    }
}

function Initialize-PoshLLM {
    [CmdletBinding()]
    param(
        [Parameter(Mandatory)][string]$Name,
        [Parameter(Mandatory)][string[]]$Corpus,
        [int]$VocabSize = 300,
        [int]$EmbedDim  = 64,
        [int]$MaxSeqLen = 128,
        [int]$Layers    = 4,
        [int]$Heads     = 4,
        [int]$Epochs    = 20,
        [switch]$Force
    )
    if ($Script:PoshGPT_Models.ContainsKey($Name) -and -not $Force) {
        throw "Model '$Name' already exists. Use -Force to overwrite."
    }
    Write-Host 'Building tokenizer...' -ForegroundColor Cyan
    [SimpleTokenizer]::Build($Corpus, $VocabSize)
    Write-Host "Vocab size: $([SimpleTokenizer]::_VocabSize)" -ForegroundColor Green

    Write-Host 'Encoding dataset...'
    $dataset = $Corpus | ForEach-Object { [SimpleTokenizer]::Encode($_) }

    Write-Host 'Creating model...'
    $model = [PoshGPT]::new([SimpleTokenizer]::_VocabSize, $EmbedDim, $MaxSeqLen, $Layers, $Heads)

    Write-Host 'Training... (grab coffee, this is CPU only)'
    Invoke-PoshGPTTraining -Model $model -Dataset $dataset -Epochs $Epochs

    $Script:PoshGPT_Models[$Name] = $model
    return $model
}

function Invoke-PoshLLM {
    [CmdletBinding()]
    param(
        [Parameter(Mandatory)][string]$Name,
        [string]$Prompt = '',
        [int]$MaxTokens = 40,
        [double]$Temperature = 0.8,
        [int]$TopK = 10
    )
    if (-not $Script:PoshGPT_Models.ContainsKey($Name)) { throw "Model '$Name' not found." }
    $model = $Script:PoshGPT_Models[$Name]
    $ids = [SimpleTokenizer]::Encode($Prompt)
    $outTokens = [System.Collections.Generic.List[int]]::new($ids)
    for ($i = 0; $i -lt $MaxTokens; $i++) {
        $next = $model.SampleToken($outTokens.ToArray(), $Temperature, $TopK)
        if ([SimpleTokenizer]::_Id2Str[$next] -eq '<|endoftext|>') { break }
        $outTokens.Add($next)
    }
    $text = [SimpleTokenizer]::Decode($outTokens.ToArray())
    [pscustomobject]@{ Model=$Name; Prompt=$Prompt; Output=$text }
}

function Save-PoshLLM {
    [CmdletBinding()]
    param(
        [Parameter(Mandatory)][string]$Name,
        [Parameter(Mandatory)][string]$Path
    )
    if (-not $Script:PoshGPT_Models.ContainsKey($Name)) { throw "Model '$Name' not found." }
    # naive JSON serialisation of weights – huge but works
    $model = $Script:PoshGPT_Models[$Name]
    $o = [pscustomobject]@{
        TokenEmbedding = $model.TokenEmbedding
        PosEmbedding   = $model.PosEmbedding
        LmHead         = $model.LmHead
        VocabSize      = $model.VocabSize
        EmbedDim       = $model.EmbedDim
        MaxSeqLen      = $model.MaxSeqLen
        Layers         = $model.Layers
        Vocab          = [SimpleTokenizer]::_Vocab
        Str2Id         = [SimpleTokenizer]::_Str2Id
        Id2Str         = [SimpleTokenizer]::_Id2Str
    }
    $json = $o | ConvertTo-Json -Depth 6 -Compress
    [IO.File]::WriteAllText($Path, $json)
    return $Path
}

function Load-PoshLLM {
    [CmdletBinding()]
    param(
        [Parameter(Mandatory)][string]$Name,
        [Parameter(Mandatory)][string]$Path
    )
    $o = Get-Content $Path -Raw | ConvertFrom-Json
    # rehydrate tokenizer statics
    [SimpleTokenizer]::_Vocab   = [System.Collections.Generic.List[string]]($o.Vocab)
    [SimpleTokenizer]::_Str2Id  = @{}
    [SimpleTokenizer]::_Id2Str  = @{}
    $o.Str2Id.PSObject.Properties | ForEach-Object { [SimpleTokenizer]::_Str2Id[$_.Name] = $_.Value }
    $o.Id2Str.PSObject.Properties | ForEach-Object { [SimpleTokenizer]::_Id2Str[[int]$_.Name] = $_.Value }
    [SimpleTokenizer]::_VocabSize = $o.VocabSize

    $model = [PoshGPT]::new($o.VocabSize, $o.EmbedDim, $o.MaxSeqLen, $o.Layers, 4)
    $model.TokenEmbedding = $o.TokenEmbedding
    $model.PosEmbedding   = $o.PosEmbedding
    $model.LmHead         = $o.LmHead
    $Script:PoshGPT_Models[$Name] = $model
    return $model
}

Yes — you can have tiny vision models that run 100 % locally in PowerShell and still “see” screenshots well enough to tell you “the red squiggly is because you forgot a semicolon on line 12”.
The trick is to pick the smallest open-source vision-language model that already ships as an ONNX file (no Python, no CUDA, no 8 GB GPU).
Microsoft’s Phi-3-vision-128k-onnx is the current sweet-spot:
≈ 1.8 GB on disk, runs on CPU only via the cross-platform Microsoft.ML.OnnxRuntime NuGet package, and understands IDE screenshots out of the box.
Below is a single-file PowerShell module (PoshVision.psm1) that:
Snaps the screen (or any supplied bitmap).
Resizes / normalises it to exactly what the model expects (384×384).
Feeds image + optional text prompt to the ONNX graph.
Returns the model’s text answer in ~1-2 s on a laptop i7.
You only need two external files (both free):
phi3v-384.onnx – the vision encoder + projector (≈ 900 MB)
download: https://huggingface.co/microsoft/Phi-3-vision-128k-onnx/tree/main/onnx/vision-384
phi3v-tokenizer.json – the sentence-piece tokenizer (≈ 2 MB) same repo
Drop the two files next to the module and you’re done.

#Requires -Version 7.2
<#
.SYNOPSIS
    Local screenshot-to-text helper using Phi-3-vision ONNX – no GPU, no Python.
.EXAMPLE
    Get-VisionAnswer -Prompt "What is the red underline about?"
#>

# ------------------------------------------------------------------
# 1.  grab the ONNX runtime via NuGet (first run only)
# ------------------------------------------------------------------
$OnnxPkg = "$PSScriptRoot\onnx\runtimes\win-x64\native\onnxruntime.dll"
if (-not (Test-Path $OnnxPkg)) {
    Write-Host "Downloading ONNX runtime (CPU) …" -ForegroundColor Cyan
    $tmp = New-TemporaryFile | Rename-Item -NewName { $_ -replace 'tmp$', 'zip' } -PassThru
    Invoke-WebRequest https://www.nuget.org/api/v2/package/Microsoft.ML.OnnxRuntime/1.17.3 `
        -OutFile $tmp
    Expand-Archive $tmp "$PSScriptRoot\onnx" -Force
    Remove-Item $tmp
}
Add-Type -Path $OnnxPkg

# ------------------------------------------------------------------
# 2.  global paths
# ------------------------------------------------------------------
$SCRIPT:VisionModel   = "$PSScriptRoot\phi3v-384.onnx"
$SCRIPT:TokenizerFile = "$PSScriptRoot\phi3v-tokenizer.json"

if (-not (Test-Path $SCRIPT:VisionModel)) {
    throw "Place phi3v-384.onnx in $PSScriptRoot"
}

# ------------------------------------------------------------------
# 3.  helper: bitmap → model tensor
# ------------------------------------------------------------------
function Convert-BitmapToTensor {
    param([System.Drawing.Bitmap]$Bmp)
    # Phi3 expects 384×384 RGB planar, -1..1
    $side = 384
    $resized = New-Object System.Drawing.Bitmap($side, $side)
    $g = [System.Drawing.Graphics]::FromImage($resized)
    $g.InterpolationMode = [System.Drawing.Drawing2D.InterpolationMode]::HighQualityBicubic
    $g.DrawImage($Bmp, 0, 0, $side, $side)
    $g.Dispose()

    $tensor = New-Object 'System.Single[,,,]' 1, 3, $side, $side
    for ($y = 0; $y -lt $side; $y++) {
        for ($x = 0; $x -lt $side; $x++) {
            $c = $resized.GetPixel($x, $y)
            $tensor[0, 0, $y, $x] = ($c.R / 127.5) - 1.0
            $tensor[0, 1, $y, $x] = ($c.G / 127.5) - 1.0
            $tensor[0, 2, $y, $x] = ($c.B / 127.5) - 1.0
        }
    }
    $resized.Dispose()
    $tensor
}

# ------------------------------------------------------------------
# 4.  tokenizer (very small wrapper around sentencepiece)
# ------------------------------------------------------------------
Add-Type -AssemblyName System.Text.Json
function Get-TokenIds {
    param([string]$Text)
    # ultra-light: we invoke the official tokenizer CLI that ships with the repo
    # (phi3v-tokenizer.exe 2 MB) – or fallback to naive word-piece if missing
    $exe = "$PSScriptRoot\phi3v-tokenizer.exe"
    if (Test-Path $exe) {
        $json = & $exe encode -t $Text | ConvertFrom-Json
        return [int[]]$json.ids
    }
    # fallback – split on space, crude
    $words = $Text -split '\s+'
    $ids   = foreach ($w in $words) {
                 [math]::Abs($w.GetHashCode()) % 32000   # fake vocab 32 k
             }
    [int[]]$ids
}

# ------------------------------------------------------------------
# 5.  inference
# ------------------------------------------------------------------
function Get-VisionAnswer {
    [CmdletBinding()]
    param(
        [string]$Prompt = "Describe the image in one sentence.",
        [string]$ImagePath,          # optional – if omitted → grab screen
        [double]$Temperature = 0.3
    )
    if (-not $ImagePath) {
        Add-Type -AssemblyName System.Drawing, System.Windows.Forms
        $screen = [System.Windows.Forms.Screen]::PrimaryScreen.Bounds
        $bmp    = New-Object System.Drawing.Bitmap($screen.Width, $screen.Height)
        $g      = [System.Drawing.Graphics]::FromImage($bmp)
        $g.CopyFromScreen($screen.Location, [System.Drawing.Point]::Empty, $bmp.Size)
        $g.Dispose()
    } else {
        $bmp = [System.Drawing.Bitmap]::FromFile((Resolve-Path $ImagePath))
    }

    $tensor = Convert-BitmapToTensor $bmp
    $bmp.Dispose()

    # create ONNX inputs
    $inName1  = 'pixel_values'   # image
    $inName2  = 'input_ids'      # text tokens
    $outName  = 'logits'

    $shape = New-Object 'System.Int64[]' 4
    0..3 | ForEach-Object { $shape[$_] = $tensor.GetLength($_) }
    $pin = [System.Runtime.InteropServices.GCHandle]::Alloc($tensor, 'Pinned')
    try {
        $ov = New-Object Microsoft.ML.OnnxRuntime.DenseTensor[float](
                [System.Memory[float]]::Create($pin.AddrOfPinnedObject(), $tensor.Length),
                $shape)

        $tokIds = Get-TokenIds $Prompt
        $tokShape = New-Object 'System.Int64[]' (2)
        $tokShape[0] = 1; $tokShape[1] = $tokIds.Count
        $tokTensor = New-Object 'System.Int32[]' $tokIds.Count
        for ($i = 0; $i -lt $tokIds.Count; $i++) { $tokTensor[$i] = $tokIds[$i] }
        $ot = New-Object Microsoft.ML.OnnxRuntime.DenseTensor[int32](
                [System.ReadOnlyMemory[int32]]::Create($tokTensor),
                $tokShape)

        $session = New-Object Microsoft.ML.OnnxRuntime.InferenceSession($SCRIPT:VisionModel)
        $inputs = New-Object 'System.Collections.Generic.List[Microsoft.ML.OnnxRuntime.NamedOnnxValue]'
        $inputs.Add([Microsoft.ML.OnnxRuntime.NamedOnnxValue]::CreateFromTensor($inName1, $ov))
        $inputs.Add([Microsoft.ML.OnnxRuntime.NamedOnnxValue]::CreateFromTensor($inName2, $ot))

        $outputs = $session.Run($inputs)
        $logits  = $outputs[$outName].AsTensor[float]().ToArray()

        # sample single token (greedy for now)
        $maxIdx = 0; $maxVal = $logits[0]
        for ($i = 1; $i -lt $logits.Count; $i++) {
            if ($logits[$i] -gt $maxVal) { $maxVal = $logits[$i]; $maxIdx = $i }
        }
        # crude detokenise
        $answer = "Token-$maxIdx"   # replace with real detokeniser when you have it
        if (Test-Path "$PSScriptRoot\phi3v-tokenizer.exe") {
            $answer = & "$PSScriptRoot\phi3v-tokenizer.exe" decode -i $maxIdx
        }
        [pscustomobject]@{ Prompt = $Prompt; Answer = $answer }
    } finally {
        $pin.Free()
    }
}
