## Overview

This guide establishes standards and procedures for moderating RawrXD community spaces including Discord, forums, GitHub discussions, and social media.

1. **Be Respectful** - Treat everyone with respect
2. **Be Helpful** - Assist others when you can
3. **Be Constructive** - Provide constructive feedback
4. **Be Inclusive** - Welcome newcomers

## Code of Conduct

### Expected Behavior

- Use welcoming and inclusive language
- Be respectful of differing viewpoints
- Accept constructive criticism gracefully
- Focus on what's best for the community
- Show empathy towards others

### Unacceptable Behavior

- Harassment or discrimination
- Trolling or insulting comments
- Personal or political attacks
- Public or private harassment
- Publishing others' private information
- Spam or excessive self-promotion
- Illegal content or activities

---

## Enforcement Guidelines

### Violation Levels

#### Level 1: Minor Violation
**Examples:**
- Off-topic discussion
- Mild language
- Unintentional spam

**Action:**
- Private warning
- Message deletion
- Educational response

#### Level 2: Moderate Violation
**Examples:**
- Repeated off-topic
- Disrespectful language
- Minor harassment

**Action:**
- Official warning
- Temporary mute (24 hours)
- Documentation

#### Level 3: Serious Violation
**Examples:**
- Harassment
- Discrimination
- Threats
- Doxxing

**Action:**
- Immediate ban
- Report to platform
- Documentation
- Potential legal action

### Appeal Process

1. **Submit Appeal** - Email community@rawrxd.local
2. **Review** - Moderation team reviews within 48 hours
3. **Decision** - Appeal approved or denied with explanation
4. **Final** - Decision is final after appeal

## Platform-Specific Guidelines

### Discord

**Channel Structure:**
- `#welcome` - Rules and introductions
- `#announcements` - Official updates
- `#general` - General discussion
- `#support` - Help requests
- `#showcase` - User projects
- `#dev` - Development discussion
- `#random` - Off-topic

**Moderation Commands:**
```
!warn @user [reason] - Issue warning
!mute @user [duration] [reason] - Temp mute
!kick @user [reason] - Remove user
!ban @user [reason] - Ban user
!slowmode [seconds] - Enable slow mode
!clear [number] - Clear messages
```

### Forums

**Categories:**
- Announcements
- General Discussion
- Support
- Showcase
- Development
- Off-topic

**Moderation Actions:**
- Pin/unpin topics
- Move topics to correct category
- Merge duplicate topics
- Close/lock topics
- Issue warnings

### GitHub Discussions

**Categories:**
- Q&A
- Ideas
- Show and Tell
- General

**Moderation:**
- Convert to issue if bug found
- Mark as answered
- Lock if heated
- Transfer to correct repo

## Crisis Management

### Negative Events

**Scenario:** Major bug causes data loss

**Response:**
1. Acknowledge issue immediately
2. Provide regular updates
3. Offer workarounds
4. Explain fix timeline
5. Follow up after resolution

**Scenario:** Community member causes drama

**Response:**
1. Private conversation first
2. Document incidents
3. Escalate if needed
4. Public statement if widespread
5. Review policies if pattern
