VWA B3-B8 LAW

1. RMV remains the only mount/identity authority.
2. VWA range code consumes only audited RMV facts; it never parses GGUF and never looks up a tensor by name.
3. Compute asks in quant-block coordinates. Arbitrary byte asks are rejected above this layer.
4. VwaResolveBlocks performs no I/O, no allocation, no residency and no scheduler work.
5. VwaFulfillExactSync uses an already-open shard HANDLE and never opens a path.
6. IOCP range transport consumes VwaPhysicalRange and writes exact bytes; it is a transport, not address authority.
7. Elastic owns lifecycle; VWA cannot publish Hot or evict.
8. The current zero-fill-on-no-sourceData path is forbidden.
9. The current Hot-with-null-gpuData path is forbidden.
10. Expert IDs lower to stacked tensor + expert-relative byte base + block range; no synthetic expert tensor names.
11. Coalescing may merge only exact physical adjacency; it cannot over-read or hide gaps.
12. Prefetch is proven only by measured overlap: overlapped wall < read + compute.
13. Bounded K2 is proven only by live peak counters under declared RAM/VRAM/outstanding-I/O budgets.
