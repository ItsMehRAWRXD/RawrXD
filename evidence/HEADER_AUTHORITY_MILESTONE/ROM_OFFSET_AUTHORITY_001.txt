=============================================================================
ROOT CAUSE IDENTIFICATION
=============================================================================

The nonfinite values were NOT caused by:
  - Corrupted GGUF file
  - NaN values in the official model
  - Wrong tensor identity
  - Quant decode errors

The nonfinite values WERE caused by:
  - STALE DATA-START OFFSET in the runtime
  - Runtime used kDataStart=3972000 instead of kDataStart=3996416
  - This caused all tensor reads to be off by 24416 bytes

=============================================================================
ADDRESS VERIFICATION
=============================================================================

For blk.0.attn_norm.weight with relative offset 289996800:

A = 289996800 (relative offset treated as absolute)
   -> 13 NaN values (unrelated tensor data)

B = 293968800 (old dataStart 3972000 + relative)
   -> 13 NaN values (CORRECT tensor, WRONG address due to stale base)

C = 293993216 (authoritative dataStart 3996416 + relative)
   -> 0 nonfinite, MIN=0.219727, MAX=7.625 (CORRECT tensor, CORRECT address)

The runtime was reading from B instead of C.
