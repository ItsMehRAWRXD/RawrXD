================================================================================
DEFECT
================================================================================
Build output + PowerShell occupied the same lower client region.
Bottom panel covered chat Send/Clear/Stop.
Console body clipped; panel tabs and splitter not reliably visible.

================================================================================
ROOT CAUSE
================================================================================
Dual bottom-surface ownership:

1) IDC_PANEL_CONTAINER (four-panel TERMINAL/OUTPUT/PROBLEMS/DEBUG) reserved the
   dock rectangle while peer m_hwndPowerShellPanel remained a full-width sibling
   that could ShowWindow over the same band (create used WS_VISIBLE; show path
   forced TabCtrl_SetCurSel(..., 4) = Build, not PowerShell index 12).

2) Legacy m_hwndOutputTabs + Build/Output RichEdit siblings were shown while the
   four-panel dock was also visible, stacking a second tab strip/body over 1300.

3) finishSession placed 1300 without subtracting status-bar height, so the dock
   temporarily overlapped the secondary-sidebar chat button row until onSize.

4) layoutPowerShellPanel freely placed the peer at mainHeight-panelH without
   coordinating the single dock owner, covering chat/splitter/tabs.

LAW: SOURCE_WIRED != RUNTIME_REACHED. This receipt records source fix + tip
rebuild hash only. Visual GUI re-probe on tip = NOT_RUN (not invented PASS).

================================================================================
FIX SUMMARY (single owner rectangle)
================================================================================
When m_panelVisible / panelDockWanted:
  - IDC_PANEL_CONTAINER owns ONE bottom rect
  - Output / Terminal / Problems / Debug share via panel tabs
  - Peer m_hwndPowerShellPanel forced SW_HIDE; m_powerShellPanelVisible=false
  - Legacy Output strip hidden
  - Body siblings (terminal panes / active Output RichEdit) only in dock body
    (bottomTop+24); panel tabs + splitter raised above body

Exclusive peer PowerShell only when four-panel dock is intentionally off.

showPowerShellPanel: if m_panelVisible → switchPanelTab(Terminal), never stack peer.
