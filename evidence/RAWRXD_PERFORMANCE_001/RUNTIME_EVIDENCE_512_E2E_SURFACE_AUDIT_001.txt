  source existence ≠ runtime evidence
  DEEP2_EV512=1 required to arm Host buffer
  SURFACE prints OBSERVED only when FindClaim returns committed record
  missing fire → NO_CORRESPONDING_RUNTIME_EVIDENCE (not fabricated)

  HostTryArm(seqCap=512, capacity=512 records)
  → claim-specific EvidenceEmit* (via HostEmit*)
  → EvidenceEmitCore XCHG(Commit)
  → HostSurfaceGuard destructor on every exit
  → EvidenceSummarize512 + EvidenceFindClaim512(id) for id=1..17
  → RXEV_SURFACE line per claim
