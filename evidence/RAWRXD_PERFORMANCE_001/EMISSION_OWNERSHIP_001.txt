LAW=
  Each claim's own runtime evidence is owned by its corresponding emission from that run.
  No claim inherits authority from another claim's emission.

  printed line L in run R  →  sole evidence owner for claims about the field L names in R
  HIDDEN_PROBE from R      →  only R may claim OBSERVED(actual) for probe
  HIDDEN_PROBE_DISPOSITION →  only that print owns NOT_REACHED / OBSERVED disposition
  STEP_ENTER / STEP_EXIT   →  only that run's prints own execute/interrupt classification
  FINAL_NORM from PATH_B_N5_003 → owns step=22 boundary for that trial only

  FINAL_NORM emit does not authorize HIDDEN_PROBE / LOGITS claims
  HIDDEN_PROBE emit does not authorize LOGITS_ENTRY / DELETE_PROVEN
  DISPOSITION(NOT_REACHED) does not invent index/value
  STEP_ENTER does not imply probe OBSERVED(actual)
  PATH_A champion wall does not authorize PATH_B PASS
  one step's emissions do not authorize another step's fields

  binary armed
  capability available
  another run's emissions
  another claim's emission in the same run
  developer labels without a matching print
  silence / missing line
