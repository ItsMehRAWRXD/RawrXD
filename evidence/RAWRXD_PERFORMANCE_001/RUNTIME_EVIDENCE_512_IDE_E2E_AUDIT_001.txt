OBJECTIVE=
  Give every claim in the shipping RawrXD IDE/product execution surface a
  claim-specific record path that CAN surface if and only if its owning real
  site fires during the measured run.

AUTHORITY_LAW=
  source existence != runtime evidence
  emitter existence != emitter fired
  claim X requires claim-X emission from that run
  emission X != authority for claim Y
  missing claim-X record = no-corresponding-runtime-evidence
  UI paint != decode
  route intent != device execution
  model path text != opened model identity
  aggregate E2E completion != substitute for missing lower-layer records
  Dropped>0 never becomes a synthetic observation
  SeqCap must equal 512

AUDIT_BASIS=
  A. Source-traced shipping Win32 IDE audit (2026-08-29):
     - actual RawrXD-Win32IDE target, boot sequence, feature stacks
     - large orphan/unwired Win32 surface identified
  B. Fake-vs-real runtime audit (2026-09-02):
     - UI pre-hooks were historically capable of impersonating forward/sample/decode
     - real GenerateStreaming/Deep2 paths identified
  C. Local-model execution finish contract (current retained source):
     - discovery -> shard/format -> arch -> quant -> tokenizer/template/EOG
       -> tensor schema -> one Deep2 session -> prefill -> generateStream
       -> real token callback -> bounded end -> cancel -> unload/reload
  D. Current RuntimeEvidence512 ABI:
     - EvidenceState 48 bytes
     - EvidenceRecord 64 bytes
     - Commit at +56, XCHG last
     - original ClaimIds 1..17 preserved

KNOWN_SHIPPING_SPLITS_REQUIRING OWNER-SITE DISCIPLINE=
  - UI stream append must never emit decode/forward/sample authority.
  - Debugger has historically had parallel stacks; instrument only the chosen
    shipping stack actually reached by the command.
  - LSP has in-process and external stacks; instrument the one actually active.
  - Extension extraction is not extension execution; dispatch/complete require
    a real QuickJS/native host.
  - Optional/local-server/voice/etc. claims remain absent when unused.
  - Orphan/unlinked TUs do not gain evidence merely because an emitter exists.
