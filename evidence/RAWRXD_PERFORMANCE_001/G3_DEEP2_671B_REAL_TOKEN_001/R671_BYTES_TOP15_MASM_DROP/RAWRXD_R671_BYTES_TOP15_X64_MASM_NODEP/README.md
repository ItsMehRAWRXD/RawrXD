# RAWRXD_R671_BYTES_TOP15_X64_MASM_NODEP

Pure x64 MASM byte-path authority for `G3_DEEP2_671B_REAL_TOKEN_001`.

This is not another residency witness. It proves the real tensor byte path:

    file_offset
        -> r671 lease
        -> lease.ptr provenance
        -> bounded view
        -> exact primitive byte consumption
        -> checksum/nonfinite evidence
        -> release closure
        -> bytes_authorized

The caller supplies raw runtime counters/addresses only. It cannot supply
witness states or `bytes_authorized`.

Native Windows build:

    build_masm.bat

Expected:

    R671_BYTES_TOP15_X64_MASM_TESTS=PASS
