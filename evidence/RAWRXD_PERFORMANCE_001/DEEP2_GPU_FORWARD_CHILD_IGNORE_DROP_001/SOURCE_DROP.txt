ONE-IGNORE LAW
  Only one selector is accepted. ',', ';', '|', '+' make the configuration invalid.
  Invalid/unknown selector => no child is ignored; GPU_FORWARD_IGNORE_VALID=0.
  No result from this diagnostic module can set PROMOTE=1.
  A child is emitted only if its own counter fired in that run.
