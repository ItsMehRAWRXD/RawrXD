Sessions
--------
SESSIONS >= 3 independent process launches (separate OS processes)
Each session:
  warmup B+C excluded
  >= 5 measured baseline trials
  >= 5 measured candidate trials
  interleaved order: B1 C1 C2 B2 B3 C3 C4 B4 B5 C5 (or same pattern extension)

Each session MUST record (before pooling):
  baseline median NS
  candidate median NS
  session REAL_SPEEDUP (median ratio)
  correctness disposition (all trials)
  environment fingerprint (CPU/GPU/driver/power plan)

Pooled statistics computed ONLY after all >= 3 sessions complete:
  POOLED_BASELINE_MEDIAN   = median(all measured baseline trials)
  POOLED_CANDIDATE_MEDIAN  = median(all measured candidate trials)
  POOLED_REAL_SPEEDUP      = POOLED_BASELINE_MEDIAN / POOLED_CANDIDATE_MEDIAN
