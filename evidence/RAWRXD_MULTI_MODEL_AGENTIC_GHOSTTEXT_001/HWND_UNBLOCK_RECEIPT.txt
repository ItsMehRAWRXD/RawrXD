ROOT_CAUSE
----------
1) PRIMARY (heap scribble when ghost paints):
   Win32IDE_GhostText.cpp used Edit-control EM_POSFROMCHAR ABI
   (wParam=cp, lParam=POINTL*) on RichEdit (MsftEdit).
   Correct RichEdit ABI: wParam=POINTL*, lParam=cp.
   Inverted args write POINTL through a small integer address → heap
   corruption family 0xC0000374 on paint (build-fd SHA 87314037…).

2) PRIMARY (feature-probe hang / fail-fast before asserts):
   runFeatureProbeCLI used pumpMessages() which dispatched
   WM_APP_RESTORE_SESSION → restoreSession() (+ deferred init).
   That path hangs or fail-fasts (0xC0000409) before any
   [feature-probe] lines. Normal startup already skips restore in
   pumpMessagesTraced; feature probe did not.

3) SECONDARY (delivery dead):
   onGhostTextReady previously rejected all WM_GHOST_TEXT_READY
   payloads (++m_ghostLegacyRejected). Product bind never ran from
   the timer/completion path.

4) SECONDARY (Ollama):
   Local provider returned "" under LOCAL_ONLY_001 with no Ollama
   fallthrough. Opt-in RAWRXD_GHOST_OLLAMA=1 + OllamaProvider FIM
   wired for multi-model GhostText (nano default).
