Purpose
-------
Answer: Does median acceleration repeat across independent, explicitly
performance-state-isolated process launches?

P1_REAL_SPEEDUP_REPEATABILITY_001 could not establish this because the
benchmark environment was not performance-state isolated (profile writes
persistent; profile dir clobbered by EnsurePolicyLoaded).

This cert does NOT reopen P1_REAL_SPEEDUP_001 (1.48× CLOSED).
This cert does NOT rewrite P1_REAL_SPEEDUP_REPEATABILITY_001 or SESSION_02.

Question
--------
Does the acceleration direction (>1.00× median) repeat when isolation
preconditions hold? Not: does every session reproduce 1.48× or 2.53× exactly.

Preconditions (ALL required before session timing counts)
---------------------------------------------------------
EXE_SHA_STABLE                  = harness EXE SHA256 verified before each session
POLICY_SHA_STABLE               = session Expert profiles unchanged vs declared
WORKLOAD_SHA_STABLE             = same model/prompt/token count as P1_REAL_SPEEDUP_001
PROFILE_DIR_EXPLICIT            = absolute profiles dir declared and recorded
PROFILE_DIR_NOT_CLOBBERED       = LearnedProfileStore dir unchanged by EnsurePolicyLoaded
PROFILE_STATE_PRISTINE_AT_START = no pre-existing learned profile for hw×model
                                  OR profile SHA recorded and unchanged if writes disabled

Profile write policy (one branch required)
------------------------------------------

    OR

If any precondition fails for a session:
  classify RUN INVALID — not SPEEDUP_FAIL, not SPEEDUP_PASS

Failure class distinction (frozen)
----------------------------------
BENCH_ISOLATION_FAIL  !=  SPEEDUP_FAIL

BENCH_ISOLATION_FAIL:
  profiles leak across declared dir
  execution state changes outside declared invariants
  EXE/model/prompt/workload authority drift
  profile dir clobbered mid-run
  → RUN INVALID (result excluded from repeatability statistics)

SPEEDUP_FAIL:
  isolation contract satisfied
  correctness held
  valid trials admitted
  session median REAL_SPEEDUP <= 1.00×
  → genuine repeatability failure (valid counterexample)
