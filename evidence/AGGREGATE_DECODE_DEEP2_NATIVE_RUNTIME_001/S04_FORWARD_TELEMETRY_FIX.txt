# AGGREGATE_DECODE_DEEP2_NATIVE_RUNTIME_001 — S04 Forward telemetry fix

## Defect
forwardCount=0 while layerCount=550 (earlier run). Root cause: BeginForward/EndForward
in ResidencyCounters.hpp were never invoked on the forward path, so forwardCount and
totalForwardMs stayed zero even though RecordLayerTime (layerCount) advanced.

## Fix
Deep2Engine_missing_members.cpp forwardTokenAllLayers():
- BeginForward() after the initial null/geometry guards.
- EndForward() before the GPU success return (tryGpuTokenForward true).
- EndForward() before the CPU per-layer failure return (safeForwardLayer false).
- EndForward() before the CPU success return (after final copy).

This brackets every real token forward (prefill + decode both route through here).
