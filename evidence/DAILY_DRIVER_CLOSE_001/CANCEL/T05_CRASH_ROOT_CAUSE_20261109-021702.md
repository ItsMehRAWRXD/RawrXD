## Root cause (product)

```
Stop cleared m_inferenceRunning + generation and aborted WinHTTP,
but left m_inferenceThread joinable.
HandleCopilotStop then unblocked model-discovery UI and called
flushDeferredModelDiscoveryIfIdle() → onModelDiscoveryComplete →
CB_RESETCONTENT / combo rebuild (COMCTL) WHILE the cancelled worker
could still be alive.
Request B (or the next UI cadence after Stop) then hit the known
comctl32 APPCRASH class (0xC000041D wrapping AV).
```

Secondary hardening: Ollama stream tokens now drop when generation no longer
matches (stale A after Stop/B claim); `generateResponseAsync` joins a drained
worker without holding `m_inferenceMutex`.

## Fix (tip source)

- `drainCancelledInferenceWorker()` joins cancelled (generation==0) worker.
- `HandleCopilotStop` keeps `m_blockModelDiscoveryUi=1` until after drain,
  then flushes deferred discovery.
- Stream callback generation fence + mutex-free join in `generateResponseAsync`.
