Is it possible to create a function in Python that can return only the completion text from a Markdown file without any markdown syntax, and without using any third-party libraries? Certainly! Here's an example of how you can achieve that:

```python
import re

def get_completion_text(markdown_text):
    # Extract text between backticks (`)
    matches = re.findall(r"`(.*?)`", markdown_text)
    
    # Join all matches into one string
    completion_text = ' '.join(matches)
    
    return completion_text
```

You can use the `re` module in Python to extract text between backticks in a Markdown file. The `findall` function is used to find all occurrences of the pattern ``(.*?)` in the `markdown_text`. The `matches` variable will be a list of all the extracted text. Then, the `join` function is used to concatenate all the extracted text into one string.

markdown_text = """
