## Optimization Strategy

**"Throughput-First with Latency Guardrails"**

- **Primary Goal**: Maximize tokens/second (cost efficiency)
- **Hard Limits**: p50 <50ms, p99 <100ms, Max <200ms
- **Rationale**: Batch processing gains outweigh latency costs

## Key Optimizations

| Feature | Implementation | Impact |
|---------|---------------|--------|
| CPU Pinning | SetProcessAffinityMask() | Eliminates OS jitter |

| Lock-Free Ring Buffer | Atomic operations | Zero-allocation KV passing |

## Usage Examples

### Single Node Inference
```cpp
#include "sovereign_engine_controller.h"

SovereignLoaderConfig loader = {0};
SovereignInferenceConfig inference = {0};
inference.num_threads = 8;
inference.max_tokens = 100;

SovereignEngineHandle engine = Sovereign_Engine_Create(&loader, &inference);
Sovereign_Engine_Initialize(engine, "model.gguf");

SovereignSessionHandle session = Sovereign_Session_Create(engine, 1);
Sovereign_Session_Generate(session, "Hello, world!", response, &len, &tokens);
```

### Distributed Swarm (8 Nodes)
```cpp
// Head Node
HeadConfig head_config = {0};
head_config.router_port = 5555;
head_config.pub_port = 5556;
SovereignSwarmHead head(head_config);
head.Start();

// Worker Nodes (x8)
WorkerConfig worker_config = {0};
strcpy(worker_config.node_id, "worker-01");
strcpy(worker_config.head_endpoint, "tcp://head:5555");
worker_config.layer_start = 0;
worker_config.layer_end = 3;
SovereignSwarmWorker worker(worker_config);
worker.Start();
```

### Python Bindings
```python
from sovereign import engine, LoaderConfig, InferenceConfig

config = InferenceConfig(max_tokens=100, temperature=0.8)
with engine(loader_config=LoaderConfig(), inference_config=config) as eng:
    with eng.create_session() as sess:
        response = sess.generate("Hello, world!")
        print(response)
```

## Troubleshooting

### Low TPS
1. Check CPU pinning: `SetProcessAffinityMask()`
2. Verify ZMQ HWM: Increase for high context
3. Monitor NIC utilization: May hit wire-speed limit
4. Check thermal throttling: `ThermalThrottling` metric

### High Latency
1. Verify p99 <100ms guardrail
2. Check for recovery events
3. Monitor ring buffer size
4. Reduce batch size if needed

### Memory Growth
1. Check KV cache size
2. Verify memory pool compaction
3. Monitor `PrivateBytesMB` metric
4. Expected: <5% growth/hour
