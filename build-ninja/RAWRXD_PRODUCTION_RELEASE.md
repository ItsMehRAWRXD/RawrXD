## Deployment Information

### System Requirements
- **OS:** Windows 10/11 x64 (Build 19041+)
- **CPU:** x64 with AVX2 support (AVX-512 recommended)
- **Memory:** 32 GB minimum (64 GB recommended)
- **GPU:** Vulkan-compatible (AMD Radeon AI PRO R9700 validated)
- **Storage:** 10 GB available space
- **Network:** Internet connection for model downloads

### Installation
```bash
# 1. Extract release package
tar -xzf rawrxd-v1.0-alpha-release.tar.gz

# 2. Set environment variables
set RAWRXD_HOME=C:\Program Files\RawrXD
set PATH=%RAWRXD_HOME%\bin;%PATH%

# 3. Run validation
%RAWRXD_HOME%\bin\ValidationRunner.exe

# 4. Start IDE
%RAWRXD_HOME%\bin\RawrXD-Win32IDE.exe
```
