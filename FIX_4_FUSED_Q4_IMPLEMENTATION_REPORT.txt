3. ARCHITECTURE
=============================================================================

Before (Separate Operations):
-----------------------------
Memory: Load Q4_0 block
  |
  v
Dequantize: Expand 4-bit -> float32 (memory write)
  |
  v
MatMul: FMA with activation (memory read)
  |
  v
Store result

Cycles: ~15-20 per element
Memory bandwidth: 2x (read quantized + read dequantized)

After (Fused In-Register):
--------------------------
Memory: Load Q4_0 block + scale
  |
  v
Unpack: VPSRLD + VPANDD (in-register)
  |
  v
Convert: VPMOVZXBD + VCVTDQ2PS (in-register)
  |
  v
Scale: VMULPS (in-register)
  |
  v
FMA: VFMADD231PS (in-register)
  |
  v
Accumulate (ZMM0-ZMM7)

Cycles: ~8-10 per element
Memory bandwidth: 1x (only quantized weights)

Performance Gain: 1.5-2x reduction in memory traffic
