## Usage

### Generate Complete Synthesis
```powershell
.\synthesis_manager.ps1 -Action architecture
```

### Individual Actions
```powershell
.\synthesis_manager.ps1 -Action synthesize    # Generate synthesis JSON
.\synthesis_manager.ps1 -Action visualize     # Create architecture diagram
.\synthesis_manager.ps1 -Action validate       # Test integration
.\synthesis_manager.ps1 -Action roadmap       # Generate roadmap
.\synthesis_manager.ps1 -Action manifest      # Create platform manifest
```
