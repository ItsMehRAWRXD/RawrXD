## Overview

The Sovereign IDE Training Curriculum provides comprehensive learning paths for developers at all levels. From basic IDE usage to expert-level SDK integration, this curriculum covers everything needed to master the Sovereign IDE.

---

## Learning Paths

### 🟢 Developer Path (Beginner → Intermediate)

For developers new to Sovereign IDE or looking to improve their productivity.

| Module | Title | Difficulty | Duration | Topics |
|--------|-------|------------|----------|--------|
| [Module 1](Module01_Getting_Started.md) | Getting Started | Beginner | 2h | Installation, first project |
| [Module 2](Module02_Code_Analysis.md) | Code Analysis | Beginner | 3h | Navigation, search, symbols |
| [Module 3](Module03_Developer_CoreFeatures.md) | Core Features | Beginner | 4h | Interface, editor, debugging |
| [Module 4](Module04_Developer_AdvancedEditing.md) | Advanced Editing | Intermediate | 4h | Snippets, refactoring, customization |
| [Module 5](Module05_Developer_Debugging.md) | Debugging | Intermediate | 5h | Advanced debugging, profiling |
| [Module 6](Module06_Developer_BuildSystems.md) | Build Systems | Intermediate | 4h | Tasks, CMake, Make |
| [Module 7](Module07_Developer_VersionControlAdvanced.md) | Version Control Advanced | Intermediate | 4h | Git advanced, hooks, submodules |
| [Module 8](Module08_Developer_Extensions.md) | Extensions | Intermediate | 5h | Extension management, marketplace |

**Total Developer Path:** 31 hours

### 🔵 Advanced Path (Intermediate → Advanced)

For developers ready to explore Sovereign IDE's advanced capabilities.

| Module | Title | Difficulty | Duration | Topics |
|--------|-------|------------|----------|--------|
| [Module 9](Module09_Advanced_BinaryAnalysis.md) | Binary Analysis | Advanced | 6h | Disassembly, CFG, patterns |
| [Module 10](Module10_Advanced_AIIntegration.md) | AI Integration | Advanced | 6h | Models, completion, analysis |

**Total Advanced Path:** 12 hours

### 🔴 Expert Path (Advanced → Expert)

For developers building extensions and integrating with Sovereign IDE SDKs.

| Module | Title | Difficulty | Duration | Topics |
|--------|-------|------------|----------|--------|
| [Module 11](Module11_Expert_ExtensionDevelopment.md) | Extension Development | Expert | 8h | Extension API, providers, views |
| [Module 12](Module12_Expert_SDKIntegration.md) | SDK Integration | Expert | 8h | Core, Agentic, Binary, AI, SEG, MoE |
| [Module 13](Module13_Expert_PerformanceOptimization.md) | Performance Optimization | Expert | 6h | Profiling, optimization, caching |
| [Module 14](Module14_Expert_Security.md) | Security | Expert | 6h | Secure development, auditing |
| [Module 15](Module15_Expert_FinalProject.md) | Final Project | Expert | 16h | Capstone project |

**Total Expert Path:** 44 hours

## Prerequisites

### Developer Path
- Basic programming knowledge
- Familiarity with version control
- Understanding of build systems

### Advanced Path
- Complete Developer Path
- Experience with Sovereign IDE
- Understanding of binary formats

### Expert Path
- Complete Advanced Path
- Extension development experience
- SDK integration knowledge

## Learning Recommendations

### For New Users
1. Start with Developer Path

3. Practice between modules
