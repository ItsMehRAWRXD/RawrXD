## Overview

Comprehensive glossary of technical terms used throughout the Sovereign IDE documentation.

---

## A

| Term | Definition |
|------|------------|
| **ABI** | Application Binary Interface - defines how software components interact at the binary level |
| **Analysis** | Process of examining binary code to extract information |
| **AST** | Abstract Syntax Tree - tree representation of source code structure |

## B

| Term | Definition |
|------|------------|
| **Basic Block** | Sequence of instructions with single entry and exit points |
| **Binary** | Executable file format (PE, ELF, Mach-O) |
| **Breakpoint** | Debugging marker that pauses execution |

## C

| Term | Definition |
|------|------------|
| **CFG** | Control Flow Graph - representation of all paths through a program |
| **Constraint** | Condition that must be satisfied in symbolic execution |
| **Cross-Reference** | Link between code locations |

## D

| Term | Definition |
|------|------------|
| **Decompiler** | Tool that converts binary code to high-level source code |
| **Disassembler** | Tool that converts machine code to assembly code |
| **Dynamic Analysis** | Analysis performed during program execution |

## E

| Term | Definition |
|------|------------|
| **Emulation** | Simulating CPU execution in software |
| **Entry Point** | Address where program execution begins |
| **Exploit** | Code that takes advantage of a vulnerability |

## F

| Term | Definition |
|------|------------|
| **Function** | Self-contained block of code that performs a specific task |
| **Fuzzing** | Automated testing technique using random inputs |

## G

| Term | Definition |
|------|------------|
| **Gadget** | Small code sequence ending in a return instruction (ROP) |
| **Graph** | Data structure representing nodes and edges |

## H

| Term | Definition |
|------|------------|
| **Heuristic** | Problem-solving approach using practical methods |
| **Hook** | Interception point for function calls |

## I

| Term | Definition |
|------|------------|
| **IDA** | Interactive DisAssembler - popular reverse engineering tool |
| **Import** | External function referenced by a binary |
| **IOC** | Indicator of Compromise - artifact suggesting intrusion |

## J

| Term | Definition |
|------|------------|
| **JIT** | Just-In-Time compilation |
| **Jump Table** | Data structure for switch statement implementation |

## K

| Term | Definition |
|------|------------|
| **Kernel** | Core component of operating system |

## L

| Term | Definition |
|------|------------|
| **Loader** | Component that loads binaries into memory |

## M

| Term | Definition |
|------|------------|
| **Malware** | Malicious software |
| **Mitigation** | Security measure that reduces vulnerability impact |
| **MoE** | Mixture of Experts - machine learning architecture |

## N

| Term | Definition |
|------|------------|
| **NOP** | No Operation - instruction that does nothing |

## O

| Term | Definition |
|------|------------|
| **OEP** | Original Entry Point - entry point before packing |
| **Opcode** | Operation code - machine instruction identifier |

## P

| Term | Definition |
|------|------------|
| **Packer** | Tool that compresses/encrypts executables |
| **Patch** | Modification to binary code |
| **Pattern** | Recognizable sequence of bytes |

## Q

| Term | Definition |
|------|------------|
| **QEMU** | Open source machine emulator |

## R

| Term | Definition |
|------|------------|
| **RE** | Reverse Engineering |
| **ROP** | Return-Oriented Programming - exploit technique |
| **Runtime** | Period during which program executes |

## S

| Term | Definition |
|------|------------|
| **Sandbox** | Isolated execution environment |
| **SEG** | Symbolic Execution Graph |
| **Shellcode** | Machine code used as payload in exploits |
| **Static Analysis** | Analysis performed without execution |
| **Symbolic Execution** | Analysis using symbolic values |

## T

| Term | Definition |
|------|------------|
| **Thunk** | Small function that jumps to another function |
| **TLS** | Thread Local Storage |

## U

| Term | Definition |
|------|------------|
| **Unpacking** | Reversing packer compression/encryption |

## V

| Term | Definition |
|------|------------|
| **Virtual Address** | Memory address in process address space |
| **Vulnerability** | Weakness that can be exploited |

## W

| Term | Definition |
|------|------------|
| **WinAPI** | Windows Application Programming Interface |

## X

| Term | Definition |
|------|------------|
| **XREF** | Cross-reference |

## Y

| Term | Definition |
|------|------------|
| **YARA** | Pattern matching tool for malware identification |

## Z

| Term | Definition |
|------|------------|
| **Zero Day** | Vulnerability unknown to vendor |
