# Native Toolchain Integration - Win32IDE Slash Commands

## Overview

Successfully integrated the self-hosting native toolchain into Win32IDE via slash commands. Users can now compile, patch, and disassemble binaries directly from the IDE chat interface.

## New Slash Commands

### `/native-compile <file.json> [output.asm]`

**Purpose**: Convert Codex JSON output to MASM-compatible assembly

**Usage**:
```
/native-compile bridge_self_host.json
/native-compile input.json output.asm
```

**Pipeline**:
1. Parse Codex JSON (AT&T syntax instructions)
2. Convert to Intel/MASM syntax
3. Emit `.asm` file ready for assembly

**Example Output**:
```asm
; Generated by Codex Native Bridge v1.0.0
; Source: self_host_test

option casemap:none

.code
align 16
    sub          rsp, 0x28                        ; Allocate shadow space
    mov          [rsp + 0x20], rbx                ; Save RBX
    mov          [rsp + 0x28], rbp                ; Save RBP
    lea          rbp, [rsp + 0x28]                ; Set frame pointer
    ret                                           ; Return
```

---

### `/native-patch <binary.exe> <patch.json>`

**Purpose**: Apply binary patches using the native toolchain

**Usage**:
```
/native-patch app.exe patch.json
```

**Patch JSON Format**:
```json
{
  "target": "app.exe",
  "patches": [
    {
      "address": "0x1234",
      "bytes": "90 90 90",
      "description": "NOP out check"
    }
  ]
}
```

---

### `/native-disasm <binary.exe> [output.json]`

**Purpose**: Disassemble binary to Codex JSON format for reverse engineering

**Usage**:
```
/native-disasm app.exe
/native-disasm app.exe app_disasm.json
```

**Output Format**:
```json
{
  "metadata": {
    "source": "app.exe",
    "architecture": "x64",
    "syntax": "intel"
  },
  "instructions": [
    {"address": "0x1000", "bytes": "4883EC28", "mnemonic": "sub", "operands": "rsp, 0x28"}
  ]
}
```

```
     │
     ▼

     │
     ▼
AgentToolHandlers::Execute({"tool": "native_compile", "args": {...}})
     │
     ▼
codex_native_bridge.exe input.json output.asm
     │
     ▼

```
