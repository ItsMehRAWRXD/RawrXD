[ 2. ROOT CAUSE - three independent defects, all measured ]
================================================================================

DEFECT_A  SSM mixer input is not normalized
  FILE=rawrxd/src/deep2/Deep2Engine.cpp forwardLayer()
  EVIDENCE (stderr, verbatim):
    LAYERDIAG call=0 layer=0 MIXER_INPUT_NORMALIZED=no attnNormTensor=1 ...
  The attention branch normalizes first (RMSNormW(lw.attnNorm, input, ...)).
  The FFN branch normalizes first. The SSM branch calls computeSSM() directly
  on the raw residual with no norm at all.
  Consequence: dt0 = ssm_in projection row block scales linearly with the
  residual magnitude, so dt = softplus(dt0 + dt_bias) reaches 1.66e5 at layer 37.
  In reference Mamba2 the mixer input is RMS-normalized, so dt is O(1e-3 .. 10).
  The selective-scan additive term delta*B*x is linear in delta, which is why
  STATE_POST grows 1.2e9x faster than CONV_OUT between layer 32 and layer 37.
  The scan is an amplifier of this defect, not itself defective.

DEFECT_B  SSM mixer output replaces the residual instead of accumulating
  FILE=rawrxd/src/deep2/Deep2Engine.cpp forwardLayer()
  EVIDENCE:
    LAYERDIAG call=0 layer=0 ... RESIDUAL_SEMANTICS=REPLACE
  computeSSM(layer, output, output) passes the same pointer as input and output.
  Every measured SSM layer has doAttn=0 doFFN=0, so this single call is the
  whole layer, and the residual is overwritten rather than added.
  Consequence, measured exactly: mixer input of layer L+1 equals mixer output of
  layer L to the last printed digit (0->2: 4.11260366 both; 28->30: 87.011 both;
  30->32: 594.359 both; 48->50: 1.4770336800e10 both). The residual stream has
  no accumulation term at all on mixer layers.
  Combined with Defect_A this compounds every mixer layer and produces the
  measured monotone-exponential growth:
    layer 0: 0.1419 -> layer 25: 7.15 -> layer 32: 594 -> layer 37: 7.85e4
    -> layer 44: 2.26e7 -> layer 50: 1.48e10      (~6x to ~15x per mixer layer)

DEFECT_C  the FFN / MoE branch emits exactly zero on every invocation
  FILE=rawrxd/src/deep2/Deep2Engine.cpp forwardLayer() -> computeMoEFFN()
  EVIDENCE: FFN_OUT absmax over all observed FFN-only layer invocations:
    FFN_OUT_ABSMAX_ZERO=68
    FFN_OUT_ABSMAX_NONZERO=0
  and LAYER_OUT absmax equals LAYER_IN absmax exactly on those layers, so the
  branch contributes nothing at all.
  The branch is NOT a stub returning a constant: the FFN norm input is non-zero
  (normInputAbsMax = 0.99, 2.08, 1.33, 2.09, 3.08 ...) and the norm weight is
  non-zero (weightAbsMax from 0.387 to 11.94). modelWeights.numExperts > 0, so
  computeMoEFFN() runs, not computeFFN(). Weights are present and correctly
  shaped in the trace:
    blk.1.ffn_gate_inp.weight  rows=128   cols=2688 type=0
    blk.1.ffn_up_shexp.weight  rows=3712  cols=2688 type=6
    blk.1.ffn_down_shexp.weight rows=2688  cols=3712 type=8
    blk.1.ffn_up_exps.weight#expert=67 rows=1856 cols=2688 type=6
  so all routed-expert and shared-expert tensors are bound. The zero is produced
  INSIDE the MoE dispatch, downstream of a non-zero router input.
  NOT_YET_LOCALIZED = the exact site inside computeMoEFFN() that zeroes output.
  This is an open defect, not a closed one.

  CONSEQUENCE: all non-attention, non-mixer capacity in this model is inert. The
  residual stream is carried by 23 mixer layers alone, which is why the growth
  is unbounded.
