4. EVENT LOOP ROUTING
=============================================================================

The following events are routed from the IDE's main window procedure to the
GhostTextIntegration layer:

1. WM_CREATE
   └── GhostTextIntegration_Initialize()
       ├── Instantiates GhostTextEngine
       ├── Initializes SovereignInferenceBridge
       ├── Sets up debounce timer (IDT_GHOSTTEXT_DEBOUNCE)
       └── Registers custom window messages

2. WM_DESTROY
   └── GhostTextIntegration_Shutdown()
       ├── Stops debounce timer
       ├── Shuts down GhostTextEngine
       └── Cleans up resources

3. WM_TIMER (IDT_GHOSTTEXT_DEBOUNCE)
   └── GhostTextIntegration_OnTimer()
       └── GhostText_OnDebounceTimer()
           ├── Checks elapsed time since last keystroke
           ├── Kills timer
           └── Triggers inference via GhostText_TriggerInference()

4. WM_KEYDOWN
   └── GhostTextIntegration_OnKeyDown()
       └── GhostText_HandleKeyNavigation()
           ├── VK_TAB: Accept full suggestion
           ├── VK_ESCAPE: Dismiss suggestion
           ├── VK_RIGHT + Ctrl: Accept partial word
           └── Other keys: Check dismiss conditions

5. WM_PAINT (Editor)
   └── GhostTextIntegration_OnPaint()
       └── GhostTextEngine::PaintGhostText()
           └── Renders ghost text overlay at cursor position

6. EN_CHANGE (Edit Control Notification)
   └── GhostTextIntegration_OnTextChanged()
       ├── Increments editorVersion (atomic)
       ├── Resets debounce timer
       └── Stores timestamp

7. Custom Messages (WM_GHOST_*)
   └── GhostTextIntegration_OnCustomMessage()
       ├── WM_GHOST_SUGGESTION: Handle inference result
       ├── WM_GHOST_DISMISS: Hide suggestion
       └── WM_GHOST_ACCEPT: Accept and insert text

6. DEBOUNCE MECHANISM
=============================================================================

Timer Configuration:
- Timer ID: IDT_GHOSTTEXT_DEBOUNCE (0x1001)
- Interval: 150ms (GHOSTTEXT_DEBOUNCE_MS)
- Behavior: Reset on every keystroke

Flow:
1. User types → EN_CHANGE received
2. Kill existing timer
3. Increment editorVersion (atomic)
4. Set new timer for 150ms
5. If user stops typing → Timer fires
6. Check elapsed time ≥ 150ms
7. Trigger inference request
8. Display ghost text on result

Stale Detection:
- editorVersion is incremented on every keystroke
- Inference results carry version number
- Results with mismatched version are discarded
- Prevents showing completions for outdated editor state

9. CURRENT INTEGRATION STATUS IN RawrXD_IDE_Win32.cpp
=============================================================================

The main IDE file (RawrXD_IDE_Win32.cpp) currently has DIRECT integration:

✅ GhostTextEngine instantiated in WM_CREATE:
   ide->ghostEngine = new GhostTextEngine(ide->hWndEditor);
   if (ide->ghostEngine && ide->ghostEngine->Initialize()) { ... }

✅ Key handling in WM_KEYDOWN:
   if (ide->ghostEngine && ide->ghostEngine->HandleKey(wParam)) { return 0; }

✅ Ctrl+Space completion trigger:
   if (ide->ghostEngine && ide->ghostEngine->IsAvailable()) {
       ide->ghostEngine->OnTextChanged(buffer, line, col);
   }

✅ WM_GHOST_SUGGESTION handling:
   ide->ghostEngine->HandleInferenceResult(gr->text, gr->line, gr->col, gr->confidence);

✅ Cleanup in WM_DESTROY:
   if (ide->ghostEngine) {
       ide->ghostEngine->Shutdown();
       delete ide->ghostEngine;
   }

The GhostTextIntegration_Wiring layer provides a CLEANER ABSTRACTION that could
be adopted to consolidate all GhostText logic in one place.
