## Why these are not in the source tree

They are binary GPU dump files totalling 163.6 MB. They are evidence, not
source, and a repository that carries them cannot be cloned cheaply. The same
failure already exists in three sibling repositories on this account that are
each ~1.9 GB scrape archives and fail local checkout with
`error: unable to create file ... Filename too long`.

## Excluded from upload entirely

```ini
real_tinyllama_f32.nqb = 4197.5 MB = NOT_UPLOADED
```

`real_tinyllama_f32.nqb` is the dense-F32 NanoF32Braid conversion of
`tinyllama-1.1b-chat-v1.0-Q4_K_M.gguf`. It exceeds GitHub's 100 MB per-file
hard limit by 42x, and LFS would require a paid quota for an artefact that is
**fully reproducible**:

```
gguf_to_nqb_converter.exe  <model.gguf>  out.nqb
```

Converter receipts for that run recorded `GGUF_TENSORS=201  CONVERTED=201
SKIPPED=0  SOURCE_NONFINITE_VALUES=0  SYNTHETIC_WEIGHTS=0  VERDICT=PASS`.

## Per-file hashes

Format: `<sha256><2 spaces><path relative to repository root>`, sorted by path.

Re-derive the whole set and compare the joined SHA-256 against
`CONTENT_ROOT_SHA256` above:

```powershell
Get-ChildItem _qoracle -Recurse -File | Sort-Object FullName | ForEach-Object {
  "{0}  {1}" -f (Get-FileHash $_.FullName -Algorithm SHA256).Hash.ToLower(),
           $_.FullName -replace [regex]::Escape((Get-Location).Path + '\'),''
}
```
