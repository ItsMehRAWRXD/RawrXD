# VAL-020.1 — Transformer Block Verification
## Composed Inference Graph Validation

**Status**: SPECIFICATION  
**Schema Version**: 2.0.0  
**Evidence Format**: rawrxd-val-020-v1  
**Date**: 2026-07-18

---

## Overview

VAL-020.1 extends the proven VAL-019 validation lifecycle from isolated primitives to a **composed inference graph**. This validates the actual execution topology of a transformer block, not just individual kernels.

### Strategic Value

| Before (VAL-019) | After (VAL-020.1) |
|------------------|-------------------|
| Embedding kernel | Embedding → RMSNorm → QKV → RoPE → Attention → KV Cache → FFN → Residual |
| RMSNorm kernel | Full transformer block |
| Individual validation | Composed execution graph |
| "Kernel works" | "Block produces correct output" |

---

## Execution Topology

```
Input Tokens
    ↓
[Embedding Layer]
    ↓ (tensor: [batch, seq, hidden])
[RMSNorm #1]
    ↓
[QKV Projection]
    ↓ (tensor: [batch, seq, 3*hidden])
[RoPE (Rotary Position Embedding)]
    ↓
[Attention Mechanism]
    ↓ (tensor: [batch, seq, hidden])
[KV Cache Update]
    ↓
[FFN (Feed-Forward Network)]
    ↓ (tensor: [batch, seq, hidden])
[Residual Connection]
    ↓
[RMSNorm #2]
    ↓
Output (next block input)
```

## Validation Lifecycle

Each stage in the topology follows the proven 6-state lifecycle:

```
[DESIGNED] → [IMPLEMENTED] → [BUILT] → [EXECUTED] → [VALIDATED] → [VERIFIED] → [ARCHIVED]
```

### Stage Breakdown

| Stage | Kernel | Input Shape | Output Shape | Dependencies |
|-------|--------|-------------|--------------|--------------|
| S1 | Embedding | `[batch, seq]` (int32) | `[batch, seq, hidden]` | None |
| S2 | RMSNorm #1 | `[batch, seq, hidden]` | `[batch, seq, hidden]` | S1 |
| S3 | QKV Projection | `[batch, seq, hidden]` | `[batch, seq, 3*hidden]` | S2 |
| S4 | RoPE | `[batch, seq, 3*hidden]` | `[batch, seq, 3*hidden]` | S3 |
| S5 | Attention | `[batch, seq, 3*hidden]` + KV Cache | `[batch, seq, hidden]` | S4 + Cache |
| S6 | KV Cache Update | `[batch, seq, hidden]` | Cache state | S5 |
| S7 | FFN | `[batch, seq, hidden]` | `[batch, seq, hidden]` | S5 |
| S8 | Residual Add | `[batch, seq, hidden]` x2 | `[batch, seq, hidden]` | S1 + S7 |
| S9 | RMSNorm #2 | `[batch, seq, hidden]` | `[batch, seq, hidden]` | S8 |

## Acceptance Gates (VAL-020.1)

| Gate | Purpose | Requirement | Verification |
|------|---------|-------------|--------------|
| **G1** | Tensor Provenance | Each tensor has SHA256 hash | Hash chain from input to output |
| **G2** | Kernel Dispatch Correctness | Each kernel executes in correct order | Execution trace matches topology |
| **G3** | Numerical Tolerance | Block output within tolerance vs reference | Max error ≤ 1e-05 |
| **G4** | Deterministic Output | Same input → same output | Repeat execution hash match |
| **G5** | Performance Telemetry | Timing captured for each stage | Per-kernel and total runtime |
| **G6** | Evidence Seal | Complete evidence chain | SHA256 manifest + verification |

```

  ├── embedding_stage.exe [VERIFIED]
  ├── rmsnorm_stage.exe [VERIFIED]
  └── ...

VAL-020.1 (Composed Block)
  └── transformer_block.exe [DESIGNED]
      ├── embedding [references VAL-019]
      ├── rmsnorm [references VAL-019]
      ├── qkv [new]
      ├── rope [new]
      ├── attention [new]
      ├── kv_cache [new]
      └── ffn [new]
```

Each new kernel in VAL-020.1 must complete its own 6-state lifecycle.
