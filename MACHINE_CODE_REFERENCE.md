# RawrXD Split Architecture - Quick Reference

## Reversed Machine Code Patterns

These are the exact opcode sequences generated by the reversed emitters.

### 1. Prologue (Stack Setup)
```
48 83 EC 28        SUB RSP, 0x28        (allocate 40 bytes shadow space)
│  │  │  │
│  │  │  └─ Immediate: 0x28 (40 decimal)
│  │  └──── ModR/M: RSP (mod=3, reg=5, r/m=4)
│  └─────── Opcode: 83h (SUB r/m, imm8)
└────────── REX.W: 48h (64-bit operand size)
```

### 2. Epilogue (Stack Teardown) - REVERSED
```
48 83 C4 28        ADD RSP, 0x28        (deallocate 40 bytes)
C3                 RET                  (return to caller)

48 83 C4 28        = 4 bytes
C3                 = 1 byte
TOTAL              = 5 bytes
```

**Reversal Proof:**
- Prologue: `SUB RSP, 0x28` → RSP becomes RSP - 0x28
- Epilogue: `ADD RSP, 0x28` → RSP becomes (RSP - 0x28) + 0x28 = RSP ✓

### 3. XOR RDX, RDX - REVERSED (Clears Return Value)
```
48 31 D2           XOR RDX, RDX         (clear RDX register = 0)
│  │  │
│  │  └─ ModR/M: 11 (mod=3, reg=2 [RDX], r/m=2 [RDX])
│  └──── Opcode: 31h (XOR r/m, reg)
└─────── REX.W: 48h (64-bit operand)
```

**Byte Breakdown:**
| Byte | Hex | Binary | Meaning |
|------|-----|--------|---------|
| 0 | 48 | 01001000 | REX.W (64-bit size) |
| 1 | 31 | 00110001 | XOR opcode |
| 2 | D2 | 11010010 | ModR/M: Src=RDX(2), Dst=RDX(2) |

### 4. The Bridge: Absolute Indirect Jump (FF 25)
```
FF 25 00 00 00 00  JMP [RIP+0]         (read address from RIP)
[8-byte Address]                        (64-bit target address)

TOTAL: 14 bytes (6 bytes opcode + 8 bytes address)
```

**Breakdown:**
| Bytes | Hex | Meaning |
|-------|-----|---------|
| 0 | FF | ModR/M escape (indirect) |
| 1 | 25 | JMP (mod=0, reg=4, r/m=5 [RIP-relative]) |
| 2-5 | 00 00 00 00 | Signed 32-bit displacement (0 = immediate follows) |
| 6-13 | [QWORD] | 64-bit target address |

**Why FF 25 Works:**
- `RIP+0` means "read the address at current RIP"
- After opcode bytes 0-5, RIP points at byte 6 (the address field)
- Processor reads 8 bytes starting at byte 6 as the jump target
- This is **position-independent** and can jump anywhere

## Stack Frame Geometry

### Call Stack Before Prologue
```
[RSP+8]     Return Address (pushed by CALL)
[RSP]       (where RSP points)
```

### After Prologue (SUB RSP, 0x28)
```
[RSP+40]    Return Address
[RSP+32]    Home for R9 (shadow space)
[RSP+24]    Home for R8 (shadow space)
[RSP+16]    Home for RDX (shadow space)
[RSP+8]     Home for RCX (shadow space)
[RSP]       (where RSP points now - 0x28 bytes lower)
```

### After Epilogue (ADD RSP, 0x28 + RET)
```
Restored to original state
RSP points back to the return address
RET pops it and jumps back to caller
```

## Machine Code Encoding Rules (x64)

### REX Prefix (One byte: 40-4F)
```
0 1 0 0 W R X B
      ↑ ↑ ↑ ↑
      │ │ │ └─ B: REX.B (extend ModR/M r/m field)
      │ │ └──── X: REX.X (extend SIB index field)
      │ └─────── R: REX.R (extend ModR/M reg field)
      └────────── W: REX.W (64-bit operand size)

48h = 01001000 = L.W.R.X.B = 0.1.0.0.0 = REX.W (64-bit)
```

### ModR/M Byte
```
M O D R E G R / M
1 1 0 0 1 0 1 0  (example: 0xCA)
│ │ └────────┘    Register/Memory
│ └──────────── Field encoded in instruction
└────────────── Addressing mode (11 = register)

ModR/M = (mod << 6) | (reg << 3) | (r/m)
```

---

## Register Encoding (All x64 Registers)

| Register | Code | REX.B | Location |
|----------|------|-------|----------|
| RAX-RDX | 0-2 | 0 | No extension |
| RDX | 2 | 0 | Standard |
| R8-R15 | 0-7 | 1 | Extended (REX.B=1) |

**Example: XOR RDX, RDX**
- RDX source = 2
- RDX dest = 2
- ModR/M = (3 << 6) \| (2 << 3) \| 2 = 0xD2
- No REX.B needed (RDX < R8)
- Final: `48 31 D2`

## FF 25 vs E9 Comparison

### Relative Jump (E9) - 32-bit
```
E9 [rel32]      (5 bytes total)
- Offset range: ±2GB from instruction end
- Fast (single byte jump)
- Limited! Can't reach high memory
```

### Absolute Indirect Jump (FF 25) - 64-bit
```
FF 25 00 00 00 00 [addr64]   (14 bytes total)
- Offset range: Full 64-bit space
- Slower (two instructions: load + jump)
- Perfect for hotpatching (can reach anywhere)
```

**Use FF 25 when:**
- Injector is far from original code (different memory region)
- Need to jump across ASLR boundaries
- Hotpatching games with unpredictable allocations

## Common Mistakes (Reversed!)

### ❌ WRONG: Using wrong displacement in epilogue
```
48 83 C4 30      ; ADD RSP, 0x30  (WRONG - mismatched prologue)
       ↑
       Should be 0x28 if prologue uses SUB RSP, 0x28
```

### ✅ CORRECT: Symmetric stack management
```
48 83 EC 28      ; SUB RSP, 0x28  (prologue)
48 83 C4 28      ; ADD RSP, 0x28  (epilogue) ← EXACT MATCH
```

### ❌ WRONG: No epilogue after call
```
FF 15 [rel32]    ; CALL [RIP+disp]
C3               ; RET ← Stack not deallocated!
```

### ✅ CORRECT: Deallocate before return
```
FF 15 [rel32]    ; CALL [RIP+disp]
48 83 C4 28      ; ADD RSP, 0x28
C3               ; RET ← Stack valid!
```

## How to Debug Machine Code

When emitted code doesn't work, check in this order:

1. **Verify REX prefix** (48 for 64-bit operations)
2. **Check displacement** (prologue/epilogue must match)
3. **Validate ModR/M** (register codes correct?)
4. **Test in isolation** (single instruction at a time)
5. **Use PEB walk** (print base address to verify)
6. **Enable DEP bypass** (VirtualProtect for injection zone)

Example validation:
```asm
mov rcx, injection_buffer
call Emit_SUB_RSP_IMM8      ; Should produce: 48 83 EC 28
; Read [injection_buffer]:
;   Byte 0 = 48? (REX.W)
;   Byte 1 = 83? (SUB opcode)
;   Byte 2 = EC? (RSP)
;   Byte 3 = 28? (displacement)
```
